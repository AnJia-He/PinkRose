## PinkRose Desktop 0.1.1

这个版本更新了桌面版的使用方式：打开软件直接进入自己的本机资料，不再要求登录。

### 本次更新

- Windows、macOS 和 Linux 桌面版不需要注册或登录。
- 每份安装和每个数据目录各自保存作品、会话、偏好和模型配置。
- 软件不会把桌面作品和会话汇总到维护者服务器。
- 设置页移除改密码、注销账号和退出登录。
- 新增「AI 与数据说明」，写清模型来源、AI 请求范围和本机数据边界。
- 不内置共享模型密钥。AI 对话和生成式改图需要使用者自己接入模型服务。
- 模型设置明确显示“未配置”，不会暗示安装包自带可用模型。

### 下载

- Windows 64 位：`windows-x64-setup.exe` 为安装版，`windows-x64-portable.exe` 为免安装版。
- macOS Apple 芯片：`mac-arm64.dmg`；Intel 芯片：`mac-x64.dmg`。
- Linux 64 位：`.AppImage` 可直接运行，`.deb` 适合 Debian / Ubuntu 安装。

首次启动会让你选择 PinkRose 数据文件夹，推荐使用「文档/PinkRose」。
以后可在「个人设置 → 文件保存位置」查看、打开或更改；迁移只复制数据，不自动删除旧目录。

### AI 与数据边界

- 安装包不包含任何 API Key，也不内置共享模型额度。
- AI 对话和生成式改图需要在「个人设置 → 模型配置」接入并启用自己的模型服务。
- 没有配置模型时，本地调色、裁剪、人像、批量、HDR、全景和导出仍可使用。
- 使用 AI 时，当前照片的必要预览、文字指令和必要上下文会发送给你配置的模型服务商。
- 模型费用、额度、数据保留和可用性由对应模型服务商决定。
- 模型 API Key 在本机加密保存，不会通过模型列表接口返回明文。

### 当前版本边界

- 安装包尚未配置商业代码签名和 Apple 公证。Windows SmartScreen 或 macOS Gatekeeper
  可能提示“未知开发者”；请只在确认下载来源为本仓库后决定是否继续。
- 当前没有自动更新器。
- RAW 在本机没有 RawTherapee、darktable 或 LibRaw 时可能只读取相机内嵌 JPEG 预览，
  不是完整 RAW 解档。
- Canon / Sony / PTP 相机控制尚未覆盖全机型，真实能力会随机型和固件变化。
- Live Photo 导出为兼容 ZIP，不是 Apple 原生 `.pvt`。
- 广色域编辑目前统一在 sRGB 工作流。
- Web / PWA 和手机布局仍在持续验证，不是本版本的主要分发入口。
