# 相机包围曝光 — 2026-10-21

## 目标

在已有实时取景、手动参数和间隔拍摄之外，补摄影工作流常用的曝光包围：
连续拍不同曝光，用于后续 HDR 合成或挑选。

## 交互

- 只有相机声明可写 `exposureCompensation` 且快门可用时出现。
- 张数 3 / 5，步长 0.3 / 0.7 / 1 EV。
- 从负曝光到正曝光逐张设置并抓拍，运行中显示进度，可停止。
- 无论正常完成、失败还是停止，都恢复开拍前的曝光补偿。
- 新照片可整组进入批量处理；不会在序列中每张替换当前编辑器。

## 计算

- 曝光序列围绕当前曝光补偿对称生成。
- 数值型 schema 按 min/max 钳制；下拉型按最接近的相机选项选择。
- 如果无法生成不重复的 3 / 5 个值，开拍前明确拒绝。

## 边界

- 依赖相机实际写入曝光补偿的速度和精度，不做厂商私有曝光算法。
- 本机无真实相机；已验证假执行器、参数顺序、曝光恢复和 WebKit 390px 布局。
- 实机可能需要关闭相机内建包围 / 连拍模式，并在长曝光时检查缓冲和 USB 锁。

## 验证

- `cameraBrackets.test.ts`：数值 / 下拉 schema、范围不足、去重。
- `CameraBridge.test.tsx`：-1 / 0 / +1 EV 三拍后恢复 0 EV。
- `check:camera-live`：WebKit 390px 控件可见且无溢出，9/9。
