# 局部修容 / 高光 —— 2026-10-18

## 目标

补齐人像妆容里常见的「修容 / 高光」。沿用「局部」的画笔蒙版、强度、
账本和撤销链路，不新增可回编辑图层，也不改全局参数。

## 像素

- 修容：按原亮度把目标阴影色缩放后混入，再乘一个约 0.72 的明度落点；
  中间调下手最稳，接近纯黑 / 高光时收一点，保留纹理。
- 高光：往暖白方向提亮，红通道抬得最多、蓝通道最少；亮度超过 90% 时
  逐渐收手，避免鼻梁高光糊成一片。
- 两者都只在掩码内写像素；覆盖率 0 的像素一个字节都不动，强度 0 恒等。

## 色板

- 修容：冷棕 / 暖棕 / 灰棕。
- 高光：香槟 / 珍珠 / 蜜桃。
- 手动涂选，不自动识别脸型或骨点；用户可用画笔 / 橡皮修边。

## 验收

- 单测：修容 luma 下降、高光 luma 上升且偏暖、掩码外 / 强度 0 不变。
- App：选择色号后提交 `{ effect: 'contour' | 'highlight', ... }`，全局参数保持 ZERO。
- 390px / iPad / WebKit：局部行仍是一行横滑，控制台无错误。
