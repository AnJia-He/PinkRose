# 社交封面 / 海报模板设计 —— 2026-10-20

## 0. 背景

用户经常不是要一张「修好的照片」，而是要一张能直接发出去的作品：小红书封面、
朋友圈九宫格中心图、短视频竖屏封面、杂志风留白。文字和贴纸工具能手工做，但
从零排标题的成本太高。这一轮提供四条固定版式，把「照片 + 标题」在一步内排好。

## 1. 模板

| 模板 | 画布 | 版式 |
|---|---|---|
| 小红书封面 | 1080×1440 | 满幅照片 + 底部渐变 + 左侧强调线 + 标题 / 副标题 / 日期 |
| 朋友圈 | 1080×1080 | 底色留白 + 圆角照片 + 居中标题 |
| 竖屏故事 | 1080×1920 | 满幅照片 + 深色渐变 + 标题 / 副标题 |
| 杂志留白 | 1080×1440 | 底色留白 + 大幅照片 + 左对齐强调线 + 标题 |

## 2. 文字

- 标题按字符宽度自动折行（中文 / 英文 / 空格都处理），最多 60 字；
- 副标题最多 80 字，日期可留空；
- 颜色只接受 `#rrggbb`，强调色同时用于强调线、日期；
- 文字复用 `image/text.ts` 的 `drawTextOptions`，预览和成片同一套排版。

## 3. 导出

- JPG（质量 0.94）或 PNG；
- 文件名 `PinkRose-poster-<模板>-YYYYMMDD-HHmm.jpg/png`；
- 全程 Canvas 本机计算，不走模型；Safari 可直接下载。

## 4. 验证

- `poster/poster.test.ts`：四种模板尺寸、照片 / 文字 / 强调线都画出、长标题折行；
- `ui/PosterPanel.test.tsx`：选照片生成预览、改标题重排、下载；
- Chromium 实测：小红书 1080×1440、竖屏故事 1080×1920，长标题折行；
- iPhone WebKit 390×844：页面无横向溢出，预览宽约 330px。
