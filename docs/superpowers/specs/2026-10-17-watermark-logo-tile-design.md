# 水印：图片 Logo 与平铺（设计）— 2026-10-17

## 0. 一句话

把原来只服务批量处理的文字水印，升级成单张导出和批量处理共用的水印能力：
文字或图片 Logo、单个或平铺，位置 / 透明度 / 大小可调，全部本机完成。

## 1. 范围

- 单张「下载 / 分享」：在导出设置里加水印；只画在导出副本上。
- 「作品 → 批量处理」：每张调色完成后、编码前画水印，随 ZIP 下载。
- 「存进作品」保持母版语义：固定 JPEG 原尺寸，不带导出水印。
- 不改小程序，不新增依赖，不调用生成模型。

## 2. 像素

- 文字：短边百分比 1~12%，可选颜色；单个位置五选一，平铺按交错网格重复。
- Logo：宽度占画面 5~40%，保持原始宽高比；支持带透明通道的 PNG。
- 平铺：横向约 1.8 个标记宽、纵向约 3 个标记高交错排列，裁到画布内。
- 透明度 10~100%；空文字或 Logo 模式未选图时一个字节都不写。
- 单张导出先复制画布再画水印，绝不把水印烤进舞台当前底图。

## 3. 界面

- 导出设置里增加可折叠的「水印」；批量页「水印」区复用同一套控件。
- 第一层选「文字 / 图片 Logo」，第二层选「单个 / 平铺」。
- 单个模式显示位置；文字模式显示字号和颜色，Logo 模式显示 Logo 大小。
- 文件选择和清除都用 label / checkbox，导出设置不新增 `.actions button`，
  避免破坏操作条按钮数量和既有探针。

## 4. 验证

- `image/watermark.test.ts`：Logo 定位、平铺覆盖、空值不画。
- `ui/WatermarkControls.test.tsx`：文字 / 平铺 / 位置和 Logo 文件接线。
- `ui/ExportSettings.test.tsx`、`ui/BatchPanel.test.tsx`、`batch/process.test.ts`：
  单张与批量的参数传递。
- `App.test.tsx`：导出副本带水印，存进作品不带水印。
- 真浏览器：导出一张平铺文字水印和一张 Logo 水印，检查像素；390px 批量页与
  导出设置无横向溢出、无控制台错误。

## 5. 不做

- 不做云端批量水印任务；所有照片都在本机浏览器里处理。
- 不改小程序的水印能力。
