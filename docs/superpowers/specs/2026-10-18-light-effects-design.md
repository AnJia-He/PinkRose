# 光效设计 —— 2026-10-18

## 目标

在「装饰」里补第五种模式：逆光 / 漏光 / 光斑 / 霓虹。全部程序化绘制，
不依赖外部素材，不调用模型；应用后写进当前这一版底图、可撤销。

## 四种光效

- 逆光：左上角暖色径向光 + 几条放射光线；
- 漏光：对角线橙红 / 洋红渐变 + 右下角暖色光斑；
- 光斑：22 个确定性分布的暖色虚化圆斑；
- 霓虹：左右青色 / 品红边缘光 + 底部紫光。

## 渲染

- `image/light.ts` 用 Canvas 渐变画在照片副本上，`globalCompositeOperation = 'screen'`；
- 强度 0 = 一个字节都不动；
- 预览 `ui/LightOverlay` 和成片共用 `drawLight`；
- 提交走 `app/baseEdit.ts` 的共享骨架，账本记一笔。

## 验收

- `image/light.test.ts`：四种预设、强度 0 恒等、每种预设都有绘制调用。
- `App.tools.test.tsx`：装饰 → 光效 → 漏光 → 应用后换底图。
- 真浏览器（Chromium + WebKit）：四颗预设、漏光预览、应用后底图出现亮部、
