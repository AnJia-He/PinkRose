# 自定义图片贴纸设计 —— 2026-10-18

## 目标

在「装饰 → 贴纸」里保留十二种内置矢量图形，同时允许用户上传自己的
PNG / WebP / HEIC 图片。自定义图保持原始比例、透明背景和方向，可拖动、
缩放、旋转；应用后写进当前版本底图、账本记一笔、可撤销。

## 边界

- 自定义图只做“图片贴纸”，不自动抠图、不去背景。
- 图片在短边百分比方框内按 contain 规则显示，最长边贴满方框，不拉伸。
- 换图会释放上一张 ImageBitmap；取消、提交、切换工具都会释放。
- HEIC 走统一 `decodeImageFile`，是否可解仍取决于浏览器 / 系统解码器。

## 验收

- 引擎单测：来源值归一化、2:1 图片在方框内保持 2:1、没有图片时明确拒绝。
- App 测试：选自定义图后预览收到 data URL，应用时第三参数收到原 ImageBitmap。
- Chromium + WebKit：真实 200×100 透明 PNG，预览和成片贴纸包围盒比例均为 2:1；
  390px 无横向溢出，无控制台错误。
