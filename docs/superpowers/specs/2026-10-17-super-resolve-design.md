# 超清放大（设计）— 2026-10-17

## 0. 一句话

在裁剪第二行提供本机「超清放大」：最多 2 倍，高品质重采样后做轻度边缘锐化，
不调用图片模型，结果写进当前这一版的账本。

## 1. 入口与交互

- 入口：`裁剪 → 超清放大`，不新增工具行第九格。
- 目标尺寸在按钮 `title` 里预告，例如「本机放大到 2400×1600，不调用模型」。
- 处理中按钮显示「放大中…」并禁用；成功后关闭裁剪并通报新尺寸。
- 已经接近本机上限时按钮禁用，不假装放大。

## 2. 像素

- 默认目标 2 倍。
- 目标尺寸再过 `fitToLimit`：受设备单边上限 / iOS 面积上限约束。
- 额外限制本机缓冲面积到 12 MP，避免锐化时两份 RGBA 缓冲把标签页拖垮。
- 重采样用 2D canvas 的 high-quality smoothing；随后做轻度 unsharp mask，
  只增强边缘反差，不改 alpha。
- 目标不大于原图时返回 null，不产生空操作。

## 3. 数据流

- 复用 `beginBaseEdit` / `discardStaleBaseEdit` / `applyBaseEdit`。
- 成功 = 当前版本换底图、账本记一笔、落盘标记 `baseChanged`。
- 不产生新历史快照、不写对话、不花钱。
- 等待期间用户换图 / 切会话 / 跳版本时，结果作废并明确提示。

## 4. 验证

- `image/upscale.test.ts`：2 倍目标、设备上限、锐化与 alpha。
- `App.tools.test.tsx`：1200×800 → 2400×1600、换底图、收工具。
- 真浏览器：尺寸变化、成功通报、零 `/api/edit` 调用、上一步退回、390px 可达。

## 5. 不做

- 不把本地插值包装成 AI 超分，不宣传不存在的模型能力。
- 不改小程序，不新增依赖。
