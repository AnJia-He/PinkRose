# 作品多选下载设计 —— 2026-10-17

## 目标

补齐作品页已有的多选能力：选中若干张作品后，一次取回它们的原图并打包成 ZIP，
不再只能逐张打开详情下载。它补的是早期作品页设计里明确留下的
「下载选中的 N 张」缺口。

## 行为

- 「多选」模式下，选择条从「已选 N 张 ｜ 删除 ｜ 取消」扩成
  「已选 N 张 ｜ 下载 ｜ 删除 ｜ 取消」。
- 下载走 `fullUrl()`（原图），不是列表用的缩略图。
- 逐张取回，文件名使用作品显示名；同名时自动加 `_2`、`_3`。
- 单张取不到不终止整批：成功项打包，失败数量写在选择条上。
- 全部失败时不给空 ZIP，状态句直接说没下载成。
- 一次最多 50 张，避免浏览器同时持有过多原图字节。
- ZIP 用现有 store-only 写入器，不新增依赖。

## 验收

- `batch/works.test.ts`：成功/失败隔离、同名去重、ZIP 内容、时间戳文件名。
- `App.gallery.test.tsx`：多选两张 → 下载一次 ZIP，并显示实际下载张数。
- 真浏览器：多选、下载 ZIP、解包确认文件数与文件名；桌面与手机选择条不溢出。
