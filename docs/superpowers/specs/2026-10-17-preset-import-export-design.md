# 预设导入 / 导出设计 —— 2026-10-17

## 目标

补齐「我的预设」设计里明确留下的分享 / 备份缺口：

- 把当前全部预设导出成一个版本化 JSON 文件；
- 从同类 JSON 文件导入预设，导入前做完整校验。

预设仍只包含 57 个调色参数，不含 Lut。导入 / 导出都在浏览器完成，服务端继续用
现有逐套创建接口，不新增接口和数据迁移。

## 文件格式

```json
{
  "format": "pinkrose-presets",
  "version": 1,
  "exportedAt": "2026-10-17T18:00:00.000Z",
  "presets": [
    { "name": "旅行暖调", "params": { "...": 0 } }
  ]
}
```

- 文件名：`PinkRose-presets-YYYYMMDD-HHmm.json`。
- 导入时 `format` / `version` 必须匹配。
- 每套名称 1–30 字；文件内不允许重名，也不允许与现有预设重名。
- 参数缺失的新键按 0 处理（`clampAdjustments`），兼容旧版本导出的文件。
- 一次最多导入到当前数量上限（30 套）；空间不够时整份拒绝，不做半截导入。

## 交互

「我的预设」第一行下方增加一行：

`导入预设 ｜ 导出全部`

旁边一句说明「只含调色参数，不含 Lut」。

- 导出：无预设时禁用；成功后提示导出套数。
- 导入：打开系统文件选择器；读取、解析、校验都失败时保留当前清单，只显示一句
  能照着做的错误。
- 校验通过后逐套调用现有保存回调。中途保存失败时如实说明已导入几套、失败的是
  哪一套，不装作全部成功。
