# 自动眼 / 自动牙（设计）— 2026-10-17

## 0. 一句话

「局部」工具新增「自动眼 / 自动牙」：用本地正脸框估出眼睛和嘴的位置，
自动填局部掩码，再交给现有「亮眼 / 牙齿」效果。用户仍可用画笔 / 橡皮修，
最后走同一条「应用局部」账本。

## 1. 选区

- 眼睛：按脸框比例左右 30% / 70%、高度 42%，两个软边椭圆；
- 牙齿：嘴部椭圆（宽 25%、高 12%）内再加颜色门：
  - 亮度高、饱和度低 → 白牙，高覆盖；
  - 红唇饱和度高 → 门压到 0；
- 两个选区都只写入当前局部掩码，不直接改像素；
- 没找到正脸、或牙齿区域没有明显露牙时，明确提示改用手动画笔。

## 2. 交互

- 局部第二行新增「自动眼 / 自动牙」两个动作按钮；
- 点击后本地检测正脸并填掩码，同时把效果切到「亮眼」或「牙齿」；
- 用户可继续用画笔补涂、橡皮修回，再调强度并「应用局部」；
- 识别期间按钮禁用并盖现有忙罩。

## 3. 验证

- `image/facePartMask.test.ts`：两眼高覆盖、嘴外为 0；白牙选中、红唇不选。
- `App.tools.test.tsx`：自动眼 / 自动牙填掩码并提交对应效果。
- 真浏览器：合成正脸自动眼 / 自动牙；眼白提亮、牙齿提亮去黄、红唇不变；
  390px 按钮可达、无控制台错误。

## 4. 不做

- 不做神经网络关键点；侧脸 / 闭眼 / 不露牙会提示手动画；
- 不动小程序。
