# 统一图层面板设计 —— 2026-10-19

## 1. 解决什么

文字 / 形状 / 贴纸 / 局部层各自有编辑控件，但没有一个地方能一眼看全：
谁在谁上面、哪层被关了、想删一层还得先开对应工具。主流修图产品都有一块
统一点图层列表，这一轮补上。

## 2. 顺序语义

- **叠图层**（文字 / 形状 / 贴纸）：`layers` 数组越靠后 = 画面上越靠上；
- **局部层**：`layers` 数组越靠后 = 越晚算，效果盖在更早的局部层上；
- 两组之间不互相插队：局部层永远作用在底图上，叠图层永远盖在它上面；
- 面板显示时两组各自**倒序**（最上面一行 = 画面上最上面那层）。

「上移」= 在组内朝画面上方挪一格；到顶 / 到底的按钮禁用。

## 3. 数据

四种层都多了一个可选字段：

```ts
visible?: boolean   // 缺省 = 显示；只有 false 才是隐藏
```

`normalizeEditLayers` 保留 `visible: false`，`sameEditLayers` 把显隐变化算成
「改过」；会话落盘、账本撤销 / 重做、刷新恢复都自动跟着走。

隐藏层**不删除**：掩码 / 位置 / 参数都还在，打开眼睛就回来。

## 4. 渲染

- `drawEditLayers` / `editLayersToBitmap`：跳过隐藏层和局部层；
- `compositeEditLayers`：只叠可见层；隐藏的局部层不参与派生；
- `applyLocalLayers`：只算可见的局部层；全部隐藏时返回 `null`，
  `useLocalLayers` 撤掉旧派生图，画布回到干净底图；
- `Canvas` 的叠图预览：跳过隐藏层；
- 导出 / 封面 / 缩略图都走同一套 `drawEditLayers` / `compositeEditLayers`。

## 5. 交互

- 面板里每行：眼睛（显示 / 隐藏）、类型图标、名字（点一下回来改）、
  上移 / 下移、删除；
- 点名字会打开对应工具并接回那一层：文字 / 形状 / 贴纸直接进编辑现场，
  局部层走 `openLocalLayer` 解回掩码和参数；
- 删除会先收起当前工具现场，再记一笔账（可撤销）；
- 没有层时整个「图层」栏不出现，不占版面。

- `shared/layers.test.ts`：`visible: false` 归一化、显隐变化比较；
- `src/image/layers.test.ts`：隐藏层与局部层都不进叠图；
- `src/App.tools.test.tsx`：面板显隐 / 上移 / 点名字回改 / 删除走账本；
- 真浏览器 390px / 1280px：文字层显隐与排序、局部层隐藏后画布真的变回、
  刷新后显隐状态恢复、删除生效、无横向溢出、控制台无错。
