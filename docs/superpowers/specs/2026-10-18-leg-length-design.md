# 人像长腿 —— 2026-10-18

## 目标

补齐全身照里常见的「长腿」。沿用正脸框下方的身体区域做几何拉伸，
不引入人体分割模型；复杂背景仍由用户走「局部 → 液化」精修。

## 算法

- 身体带：从脸上方 0.82×脸高开始到画面底部，水平范围约 ±0.95×脸宽
  （至少画布宽度的 24%）。
- 输出像素向上取样（`srcY -= 0.10×身体高度×强度×垂直×水平`），带内内容
  整体下移，视觉上腿变长。
- 最上（靠近脖子）和最下（靠近画面底）都用 smoothstep 淡出，避免横向接缝；
  脸本身和画面外侧不动。
- 强度 0 恒等；只改当前底图，可撤销。

## 验收

- 单测：身体中段白线被拉到下方，脸和身体外不变。
- App：拖动「长腿」后预览与提交都带 `legs`，全局参数保持 ZERO。
- 390px / iPad / WebKit：人像行仍可横滑，主按钮和取消够得着。
