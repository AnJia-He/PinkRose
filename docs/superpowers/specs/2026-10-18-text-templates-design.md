# 文字模板（设计）— 2026-10-18

## 0. 一句话

文字工具新增六套常用模板：**标题 / 极简 / 胶片 / 杂志 / 旅行 / 手记**。
点一下套用字号、颜色、粗细、阴影、描边和底色，用户再继续改；文字内容和位置
不动。

## 1. 为什么是它

醒图、美图秀秀、Canva 的文字工具都从模板开始。现有文字工具功能齐全，但每次
都要手动调字号 / 颜色 / 描边 / 底色，社媒用户最常用的是几套固定风格。

## 2. 模板数据

`src/image/text.ts` 的 `TEXT_STYLES`：

- 字号用**照片短边比例**（`fontRatio`）而不是固定像素，1200px 和 4000px
  的图不会一个太大一个太小；
- 模板只覆盖样式字段，`text` / `x` / `y` 原样保留；
- 六套：
  - 标题：10% 短边、白、加粗、阴影；
  - 极简：5%、白、左对齐、无效果；
  - 胶片：6%、暖白、阴影；
  - 杂志：7%、白、加粗、黑底 68%；
  - 旅行：6.5%、白、加粗、3px 黑描边 + 阴影；
  - 手记：5%、深色字、米色底 82%。

## 3. 界面

- 文字第二行在输入框后面加一排「文字模板」胶囊；
- 点击套用，不关闭工具、不动文字；
- 仍在同一条横滑带里，不增加第二行高度；
- 应用 / 取消 / 账本链路完全不变。

## 4. 验证

- `App.tools.test.tsx`：点「标题」→ 字号 80（1200×800 短边 ×10%）、加粗、
  阴影，文字内容不变；点「杂志」→ 底色 68%；
- `check:safari`：WebKit / 390px 下点「标题」，字号变为 30（600×300 短边 ×10%）；
- 全量测试、typecheck、build、layout、copy。

## 5. 不做

- 不做自定义模板保存 / 分享；
- 不做字体上传；
- 不改小程序界面。
