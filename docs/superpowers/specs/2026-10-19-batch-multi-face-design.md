# 批量合影多人脸精修设计 —— 2026-10-19

## 0. 背景

批量人像原来只取画面里最大的一块肤色连通域，合影里除了最大那张脸，其他人都不会
被磨皮、补光、美白、去斑或瘦脸。对摄影师和家庭用户来说，这是“批量精修”最容易
被一眼看出的漏项。

## 1. 检测

- `core/faceDetect.ts` 保留原来的单脸 `detectFaceBox` 行为；
- 新增 `detectFaceBoxes`：同一套肤色掩码和连通域，放宽尺寸 / 边缘限制，按面积
  从大到小取候选，用 IoU > 0.35 去掉同一张脸被拆成的重复框，最多 6 张；
- `image/faceDetect.ts` 新增 `detectFacesInBitmap`，仍在长边 ≤640 的副本上检测，
  再按比例放回原图。

它不是神经网络；只用于用户主动打开「合影多人脸」。误检仍被软边脸框限制，
不会重画整张照片。

## 2. 像素链路

- 磨皮：每张脸的 `faceMask` 取逐像素最大值，合成一张掩码后只跑一次引导滤波；
- 去斑 / 补光 / 美白红润：逐张脸跑，后一张在前一张结果上继续；
- 塑形：最大的一张脸做完整塑形；其余脸只做瘦脸 / 微笑，瘦颈 / 双下巴 / 肩线
  是身体级关系，重复做会把身体拉多次；
- `BatchOutcome.portraitFaces` 报告实际覆盖的人脸数。

## 3. 界面

- 批量页「人像精修」里多一个「合影多人脸」开关，默认关，保持单脸旧行为；
- 结果区在开启时显示「共处理了 N 张脸」；
- 文案明确提示背景暖色块可能被误认，建议先用小批试。

## 4. 验证

- `core/faceDetect.test.ts`：两张分开的肤色区域 → 两个框；`maxFaces` 截断。
- `batch/process.test.ts`：多人脸走 `detectFacesInBitmap`，单脸检测不跑；
  两张脸的蒙版合并后磨皮只跑一次；覆盖脸数正确。
- `BatchPanel.test.tsx`：开关值传给处理器，结果显示覆盖脸数。
- 真 Chromium：上传合成的双人肤色图，开「合影多人脸」+ 磨皮 30，处理成功
  1 张并显示「共处理了 2 张脸」。
