# 天空背景预设（设计）— 2026-10-17

## 0. 一句话

现有「智能主体 / 换背景」里加入三种本地生成的天空：**晴空 / 日落 / 暮色**。
人物仍由主体掩码抠出，背景由 Canvas 渐变、柔光太阳、软云 / 星点生成，不依赖
外部素材或模型。

## 1. 像素

- 三种预设各自三段以上渐变；
- 晴空：蓝到浅蓝，偏右上太阳柔光 + 三团软云；
- 日落：紫到橙金，低处太阳柔光 + 两团暖色云；
- 暮色：深蓝紫到暖橙，少量星点 + 低处太阳余晖；
- 尺寸与底图一致，合成仍先压主体 alpha 再盖到天空上。

## 2. 界面

- 「点修 → 抠图」背景下拉新增「晴空 / 日落 / 暮色」；
- 选中后主按钮变「换背景」；
- 仍走 `baseEdit`：新底图、账本一笔、可撤销，不花模型额度；
- 手机第二行不增高，下拉横向可达。

## 3. 验证

- `App.tools.test.tsx`：晴空 / 日落选择传给合成层的 `{kind:'sky', preset}`；
- 真浏览器：真实人像日落天空，背景变化、脸和头发保留、390px 不溢出；
- 全量测试、typecheck、check:copy。

## 4. 不做

- 不做真实天空语义匹配 / AI 生成；
- 不动小程序。
