# AI 扩图（设计）— 2026-10-17

## 0. 一句话

把原图居中放进目标比例画布，用现有图片模型自然补画四周；结果作为新的一版进入
历史和账本，用户可以继续调色、撤销或导出。

## 1. 入口与交互

- 入口放在「裁剪」第二行：`裁剪 → AI 扩图`，不新增第九颗工具行格子。
- 比例：1:1 / 4:5 / 3:4 / 9:16 / 16:9。
- 页内明确写「会调用图片模型，约 10 秒；生成后是新的一版，可撤销」。
- 只有在当前最新一版上才能生成；不是最新时给一句「先回到最新一版再扩图」。
- 生成中主按钮禁用并显示「正在扩图…」；用户仍可用全站「停止」。

## 2. 像素与提示词

- 先用 `expandCanvas(..., 'mirror')` 把原图放进目标比例，四周给镜像 / 虚化上下文。
- 提示词要求：保持中央原图的身份、姿势、表情、颜色、光线、构图不变；把引导边
  替换成自然真实的环境延续；不许裁切、缩放、移动原画面；不许加文字、Logo、边框、水印。
- 送模型前继续走 `prepareForModel`：长边 ≤ 2048、边长对齐 32。

## 3. 数据流

- 复用 `useGeneration.runGenerate`：一次生成 = 一个快照、一条助手消息、一次落盘。
- 生成成功换 `base`；参数原样保留，调色继续有效。
- 失败 / 停止沿用现有生成路径：失败给「再试一次」，停止不写快照、不丢参数。

## 4. 验证

- `export/outpaint.test.ts`：目标尺寸、提示词约束、回复文案。
- `ui/OutpaintControls.test.tsx`：比例、说明、生成回调、禁用态。
- `App.tools.test.tsx`：裁剪进入 → 选 4:5 → 送扩过画布的请求 → 成功后收工具。
- 真浏览器：拦截 `/api/edit` 返回合成图，验证新底图比例、工具收起、390px 无溢出。

## 5. 不做

- 不在导出时静默调用模型；扩图必须由用户明确点击。
- 不改小程序，不新增依赖。
