# 相机拍摄参数预设设计 —— 2026-10-20

## 目标

相机桥已经能实时取景、按快门和调整适配器暴露的参数；摄影师换场时还需要
把一套 ISO / 光圈 / 快门 / 白平衡 / 测光等参数保存下来，下一次一键恢复。

## 行为

- 「存为我的参数」把当前可控相机的全部设置存成一个命名快照。
- 快照按 **名称 + 机身型号** 去重，同名覆盖；最多 20 条，只存本机 localStorage。
- 「套用预设」只处理当前相机 `settingsSchema` 里存在、可写、类型匹配的项：
  - 数字按 min / max / step 钳制并取整到步长；
  - 下拉值必须仍在当前选项里；
  - 读只读项、未知键、别的机身的专属键一律跳过。
- 应用成功后照常 PUT `/api/camera/settings`，由相机适配器真正下发。

## 为什么不存成"内置人像 / 风光预设"

不同厂商的键名、ISO 档位、光圈步长、白平衡枚举都不一样。内置创意预设
需要为每个 adapter 各写一套映射，容易把"人像"套成完全不同的参数。
用户自己的快照以当前相机真实 schema 为准，换机身时也只复制能用的部分，
不会硬塞一个不适用的值。

## 验证

- `core/cameraPresets.test.ts`：保存 / 同名覆盖 / 删除 / 20 条上限 / 坏数据；
  schema 过滤、数字步长与范围、下拉合法性。
- `ui/CameraBridge.test.tsx`：可控相机保存快照 → 改乱当前值 → 套用预设后
  PUT 恢复，删除后下拉消失。
