# 局部眼影设计 —— 2026-10-18

## 目标

在「局部」里补一个眼影效果：用户先用手动画笔涂眼皮，再选色号，
应用后只改当前这一版底图的眼皮区域。不调用模型，不写全局参数。

## 为什么手动画

眼白、虹膜、睫毛和眼皮贴得很近；本地正脸框能估眼睛位置，但分不清
眼睑和眼球。第一版明确做「先涂再上色」：用户能看见蒙版、能用橡皮修边，
不承诺自动识别眼睑。

## 色号与算法

- 大地棕 / 珊瑚橘 / 玫瑰粉 / 紫罗兰 / 雾蓝 / 香槟金。
- 按原亮度缩放目标色；只混入覆盖率 × 强度 × 55%，保留眼皮纹理和高光。
- 掩码外逐字节不变；强度 0 为恒等。

## 验收

- `image/localAdjust.test.ts`：掩码外不动、偏粉、强度 0 恒等。
- `App.tools.test.tsx`：涂过 + 选玫瑰粉 + 应用，提交
  `{effect:'eyeshadow', eyeShadowShade:'rose'}`。
- 真浏览器（Chromium + WebKit）：眼皮 r-g 明显上升，下方皮肤 0 变化；
  390px 六个色号都在且不横向溢出。
