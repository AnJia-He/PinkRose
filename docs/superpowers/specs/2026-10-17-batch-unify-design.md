# 批量统一画幅 / 自动增强（设计）— 2026-10-17

## 0. 一句话

在批量处理里增加统一画幅和逐张自动增强：每张照片先按自己的画面校正，
再裁成统一比例、套所选风格、加水印、导出。

## 1. 界面

- 批量页在「照片」与「调色」之间新增「统一处理」。
- 画幅：保持原样 / 1:1 / 4:5 / 3:4 / 9:16 / 16:9。
- 「每张自动增强」默认关闭；打开后逐张分析，不共用第一张的参数。
- 修改任何统一项都清掉上一批结果，避免旧 ZIP 冒充新结果。

## 2. 处理顺序

1. 解码。
2. 非原样画幅：居中裁成目标比例。
3. 按导出长边缩图。
4. 若开启自动增强：对**当前裁后图**采样，算保守自动参数。
5. 自动参数覆盖所选预设的曝光 / 对比 / 高光 / 阴影 / 饱和度 /
   自然饱和度 / 色温 / 洋红—绿，其它创作参数保留。
6. WebGL 调色 → 水印 → EXIF / 编码 → ZIP。

## 3. 边界

- 全部本机处理，不调用 AI 模型。
- 画幅为居中裁切；本轮不做逐张手动取景。
- 单张失败继续处理后面的照片。

## 4. 验证

- `batch/process.test.ts`：居中裁切参数、自动参数覆盖与预设保留。
- `BatchPanel.test.tsx`：控件状态传入批处理。
- 真浏览器：1200×800 裁成 800×800、自动增强后成片正常、390px 不溢出。
