# XMP 预设互操作 — 2026-10-21

## 目标

让「我的预设」能和桌面修图软件交换单套调色，同时保持 PinkRose 自己的完整参数
能无损往返，不把部分映射包装成完整 Lightroom 兼容。

## PinkRose XMP

- 使用 `pinkrose` 自定义命名空间保存全部 `PARAM_KEYS`。
- 同时写常见 `crs:` 基础项，方便其它软件读取。
- 导入时只要发现 `pinkrose:` 参数，就优先使用它，全部参数无损恢复。
- 文件名使用 `PinkRose-look-时间.xmp`。

## 第三方 XMP 子集

当前映射：

- 曝光（EV × 20 → -100..100）；
- 对比 / 高光 / 阴影 / 白色色阶 / 黑色色阶；
- 清晰度 / 纹理 / 去雾；
- 自然饱和度 / 饱和度；
- 锐化（150 → 100 缩放）；
- 降噪 / 颗粒 / 暗角。

不映射 HSL、曲线、颜色分级、镜头、人像几何、LUT 和局部蒙版。导入后未映射项
保持零值，这是兼容子集而不是完全等价的 Lightroom 预设。

## 边界

- XMP 只承载调色参数，不承载 Lut。
- 只接受单套 XMP；JSON 仍用于整组备份 / 恢复。
- 第三方字段的语义和范围可能因软件版本变化，当前以 Camera Raw 常见字段为准。
- 自定义命名空间保证本产品自己的 XMP 可完整回读。

## 验证

- `presetFile.test.ts`：全参数 XMP 往返、第三方字段映射、乱文件拒绝、文件名。
- `PresetManager.test.tsx`：导入 XMP、导出当前 XMP。
- `npm run check:safari`：WebKit 390px 实际下载 XMP 并检查 XML 内容，完整探针 56/56。
