# 文字行距与字距设计 —— 2026-10-18

## 目标

给文字工具补上主流排版产品常见的行距与字距控制，预览和成片使用同一组
图片像素值，并保持现有模板、描边、阴影、底色和旋转。

## 选项

- `lineHeight`：0.8~2.0，默认 1.2；排版行距 = 字号 × 倍数。
- `letterSpacing`：-20~40 图片像素，默认 0。
- 字距为 0 时仍整行绘制，保留字体自身的 kerning；非 0 时逐字绘制，
  在每个字符后额外加字距，跨 Chromium / WebKit 行为一致。

## 预览

CSS 的 `line-height` 和 `letter-spacing` 都乘屏幕缩放比例；底色块宽高按
字距后的实际宽度重新计算。

## 验收

- 选项夹取、行距位置、逐字绘制坐标。
- App 控件值同时进入预览和 `textToBitmap`。
- Chromium + WebKit：字距 0→20 时文字包围盒变宽，行距 1.2→2.0 时
  两行文字包围盒变高；390px 无溢出，无控制台错误。
