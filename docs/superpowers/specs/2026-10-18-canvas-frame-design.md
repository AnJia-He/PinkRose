# 单图画布扩展设计 —— 2026-10-18

## 目标

在「装饰」里补一个单图画布工具：把照片放进原图 / 1:1 / 4:5 / 3:4 /
9:16 / 16:9 画布，背景可选纯色、当前照片的模糊版本或透明，边距 0~20%。
先在照片上准确预览，应用后写进当前版本底图、账本记一笔、可撤销。

## 布局

- 先按「照片不缩小」算出目标比例的内容盒：横图做 1:1 时上下补，竖图
  做 16:9 时左右补。
- 再按边距把内容盒放进最终画布；长边最多 4096，超过时整张等比缩小。
- 照片始终居中、不拉伸；预览和成片共用 `canvasFrameLayout` /
  `paintCanvasFrame`。

## 预览

把当前 WebGL 画布（含调色结果）重绘到目标画布，而不是只拿上传原图。
预览层盖住原照片区；透明背景显示棋盘格。成片 PNG / WebP 保留 alpha。

## 兼容

WebKit 在 WebGL canvas 原地改变宽高后可能不合成新帧。`Canvas` 现在在底图
尺寸变化时换一个 `<canvas>` 元素并重建管线，这同时修复裁剪、画布等所有会
改变尺寸的底图操作。

## 验收

- 布局单测：原比例、1:1、9:16、10% 边距、4096 上限。
- 绘制单测：纯色、模糊、透明、照片居中。
- App：装饰 → 画布 → 4:5 + 模糊 + 边距 10 → 应用。
- Chromium + WebKit：390px 无溢出；预览有颜色；最终画布 1000×1000；
  模糊背景不是空白；控制台无错误。
