# 液化（设计）— 2026-10-17

## 0. 一句话

在「局部」工具里加入「液化」子模式：推移 / 收拢两种笔触，先在工作副本上
连续改，点「应用液化」才写进当前这一版底图、账本记一笔、可撤销。

## 1. 为什么做成「局部」的子模式

工具行已经有七颗格子，再塞一颗会让窄屏第一排溢出。液化本来就是局部改像素，
和「局部色」是同一类现场，所以从 `LocalControls` 里切进去；液化有自己的第二行，
「调色」可以切回局部色。工具行的「局部」格子在这期间保持点亮。

## 2. 笔触

```ts
type LiquifyStroke = {
  x0, y0, x1, y1: number   // 一笔的起止点，图片像素
  radius: number            // 笔刷半径
  strength: number          // 0~100
  mode: 'push' | 'pinch'
}
```

- `push`：目标像素反向采样 `src = p - delta * strength * falloff`；
- `pinch`：`src = center + (p - center) * (1 + 0.7 * strength * falloff)`；
- `falloff` 用 smoothstep 从笔触中心到半径边缘衰减到 0；
- 只处理笔触外接框，源块向外扩出最大位移再双线性采样；
- 强度 0 / 没拖动 = 一个字节都不动；贴边也不越界。

## 3. 工作副本与预览

- `useLiquify` 在进入时把底图画进一块离屏 2D 画布（`willReadFrequently`）；
- 每次松手只重采样笔刷覆盖的区域，再把工作画布生成一张预览位图交给 Canvas；
- Canvas 显示的 `image` 是预览位图，App 自己的 `image` 仍是提交 / 账本认的底图；
- 「重来」重画工作画布、释放预览；
- 提交时用工作画布生成新底图，走 `app/baseEdit.ts`；取消/切走释放预览。

## 4. 界面

- 局部第二行多一颗「液化」；
- 液化第二行：调色 / 推移 / 收拢 / 笔刷 / 强度 / 重来 / 取消 / 应用液化；
- 照片上的 `LiquifyOverlay` 画笔刷圈和方向线，松手才交出一笔；
- 工具行「局部」保持点亮，液化没有自己的格子。

## 5. 不做什么

- 不做自动人脸关键点 / 自动瘦脸（这一版是手动推 / 收）；
- 不做逐笔撤销（只有「重来」清掉整趟）；
- 不做可回编辑的形变层（应用后烘焙进底图）；
- 不动小程序界面。
