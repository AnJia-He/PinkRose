# 批量成片存进作品设计 —— 2026-10-20

## 0. 背景

批量处理原来只有「下载 ZIP」。用户如果想把成片留在作品集里，得先下载、解压、
再一张张上传。批量结果现在已经有成片 Blob 和缩略图，直接入库是自然的一步。

## 1. 实现

- `BatchSuccess` 保留成片 `blob` 和 160px `preview`；
- 结果区有可保存项时出现「存进作品」；
- 逐张 `blobToDataUrl` → `createWork({ image, thumb })`；
- 入库成功后 `renameWork(id, filename)` 把作品别名写成导出文件名；
- 单张失败只计数，不中断后面的照片；结果区报告成功 / 失败张数。
- 每张成片旁另有单独下载按钮，不用为了拿一张图下载整个 ZIP。

## 2. 边界

- 走当前登录账号的作品配额和上传限制；单张超大图失败时只跳过该张；
- 不自动删除源文件，不改变 ZIP 下载；
- 不写作品配方（批量套用的参数不混进单张详情），只保留图像和名字。

## 3. 验证

- `BatchPanel.test.tsx`：有 Blob 时出现按钮，调用 `createWork` / `renameWork`；
- `batch/process.test.ts`：成功项带 Blob；
- iPhone WebKit 390×844：处理两张后点「存进作品」，提示「已存进作品 2 张」，
  服务端作品列表新增 2 条，测试后删除。
