# 全景拼接设计 —— 2026-10-18

## 目标

给 Web 修图产品补上全景拼接：从本地按拍摄顺序选 2–8 张有重叠的照片，
自动找相邻两张的重叠区域，横向或纵向拼成一张长图并下载。全部在本机完成，
不调用模型，不增加一级导航。

入口放在「作品」页头，和拼图、批量处理、证件照、打印排版并列。

## 重叠检测

- 横向时每张照片缩到高 64px 的灰度图；纵向时缩到宽 64px。
  用归一化互相关（NCC）比较相邻两张的接缝边缘。
- 候选重叠范围：接缝方向长度的 8%–60%，逐像素搜索。灰度图很小，
  逐像素比按步长跳更稳：步长会让真正的接缝落在两个候选之间。
- 只在相关系数 ≥ 0.2 时采用检测结果；低于阈值按 0 重叠拼接，
  不硬猜。

## 排版与接缝

- 横向时所有照片统一到目标高度，宽度按各自比例换算；纵向时统一到目标宽度，
  高度按各自比例换算。
- 横向的 x 由上一张宽度减去重叠量累加；纵向的 y 由上一张高度减去重叠量累加。
- 每个接缝把先一张的边缘按 1→0 的 alpha 渐变盖到后一张上，
  形成柔和过渡。预览和成片共用 `renderPanoramaCanvas`，
  接缝位置不会预览一套、导出另一套。
- 总像素上限 36 MP；超过时等比降低输出高度。

## 导出

- JPG / PNG / WebP；JPG / WebP 质量 60–100。
- 短边：1200 / 1600 / 2000（横向时是高度，纵向时是宽度）。
- 文件名：`PinkRose-panorama-YYYYMMDD-HHmm.<ext>`。
- 解码、渲染、编码期间显示进度，可停止；取消或异常时关闭所有
  `ImageBitmap`，不留下半成品。

## 验收

- `image/panorama.test.ts`：50px 重叠检测、排版位置、文件名。
- `ui/PanoramaPanel.test.tsx`：至少两张才能生成、顺序上移 / 下移、
  生成后下载与再下载。
- `App.gallery.test.tsx`：作品页进入全景、返回作品页。
- 真浏览器（Chromium + WebKit）：磨皮滑杆 / 画笔、全景预览与成片尺寸、
  接缝像素贴合、控制台无错误。
