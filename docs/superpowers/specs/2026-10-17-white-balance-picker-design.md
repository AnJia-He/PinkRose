# 白平衡吸管（设计）— 2026-10-17

## 0. 一句话

调色面板「色彩」组加一颗「白平衡吸管」：用户点一下画面里的灰面或白面，
按这块中性色的 RGB 偏差，自动写回 **色温** 和 **洋红 — 绿** 两条白平衡轴。
不联网、不花钱、不改曝光等其它参数。

## 1. 为什么读底图

吸管读 `image.bitmap`，不读已经带着参数和 Lut 的屏幕画面。

白平衡是**底片层**的校正：它应该回答"这张原片偏什么色"，而不是"当前这层
滤镜看起来偏什么色"。读底图还有一个直接好处：用户先套了风格 Lut、再回来用
吸管时，校正结果不会被 Lut 的颜色二次污染。

## 2. 取样

`image/sample.ts` 的 `samplePixelAt(source, nx, ny)`：

- 坐标归一化，和画布点选同一套；
- 取短边 0.6%、至少 1px 的方块做面积平均，避开单像素噪点；
- 越界夹在画面边缘。

## 3. 反解两条轴

shader 的白平衡步是：

```
r += temperature * 0.10 + cbCyanRed * 0.10
g += cbMagentaGreen * 0.10
b -= temperature * 0.10 + cbYellowBlue * 0.10
```

让红/蓝先相等，得到：

```
temperature = 500 * (b - r)          // r/g/b 为 0~1
cbMagentaGreen = (1000 / 3) * (r + b - 2g)
cbCyanRed = cbYellowBlue = -cbMagentaGreen / 2
```

红蓝两根平衡轴按 `-mg/2` 配平，三轴和为零，所以校正色偏时不顺手改变整体明暗。
两条轴都钳在 -100~100 并取整。

## 4. 什么样本不接

亮度 < 0.08、亮度 > 0.97、最大通道差 > 0.35 时返回 null。太黑有噪点、太亮
已经削顶、彩色区域本身不是中性色。界面明确说「换一块灰色或白色再点」，不给
一组看起来专业但错误的数字。

## 5. 界面

- 「色彩」组底部一颗带 `Pipette` 图标的「白平衡吸管」；
- 点开后画布进入取样态，顶部提示「点一下画面里的灰色或白色」；
- 点中后立即写参数，按钮退出取样态；
- 再次点按钮 = 取消；切屏 / 换图 / 其它点选流程开始时一起清掉；
- 与 AI 点选互斥：开吸管会取消待确认的图上点选。

## 6. 验证

- `core/whiteBalance.test.ts`：中性灰归零、暖偏色回正、绿偏色方向、暗/亮/重彩拒绝；
- `App.adjust.test.tsx`：按钮进入取样、点画面写两轴、其它参数不动、不调用生成；
- 真浏览器：偏暖灰 `200,190,170` 点完后变 `187,187,187`，色温 `-59`、
  洋红—绿 `-13`，控制台无错误；
- `check:layout` / `check:copy` / 全量单测。

## 7. 不做什么

- 不做自动识别灰卡 / 人脸肤色白平衡；
- 不读屏幕合成后的带 Lut 画面；
- 不动小程序界面。
