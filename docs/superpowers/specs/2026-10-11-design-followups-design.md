# 设计跟进：设置页重设计 + 体检六件（2026-10-11）

> **来源**：用户「以管产品设计的角度看还缺什么，比如设置页看起来很业余很散漫」→
> 真机设计体检（报告在 `.superpowers/scratch/design-audit/report.md`，40+ 张截图）+
> 控制器亲自看过的设置页截图；用户「一切你有所有权限」= 批准本批全部动手。

## 一、设置页为什么"业余、散漫"（病根，2026-10-11 亲眼复核）

1. **三格并排是"仪表盘"排版，三块内容量差五倍**（账号 3 行 / 模型 1 行 / 用量一整张
   300px 高的大饼图）→ 同排并列必然高低参差；
2. 「退出登录」孤零零悬在左下、底下大片空白；
3. 「模型配置」就一行内容还给一整张卡 → 空壳感；
4. 版心 1200px 装这些内容本来就太大——散的主因是**版式选错了**（并列 vs 单列）。

**新样子（用户已看过线框图并批准方向）**：单列分组、版心收窄到 680px 居中：

```
个人设置
账号
   用户名               ›
   改密码               ›
   注销账号（红）        ›
模型配置
   模型          默认    ›
作品空间用量
   [饼图·左]  [剩余 >99.9% / N 张作品·右]   ← 宽屏横排；窄屏自然叠
（列底）退出登录
```

- 全部"就地展开"交互、文案、测试锚点类**一个不删**（`.account-row` / `.account-label` /
  `.account-name` / `.account-stats` / `.account-signout` / `.account-form` /
  `.account-quota-warn` 等，见 `App.account.test.tsx` 的用法）。
- 饼图组件内部（几何/配色/那两条压在饼上的标签文字）**一个字不动**；只是把
  百分比那行从组件里搬出来、和「N 张作品」一起组成右列。做法：`UsagePie` 不再渲染
  `.usage-pie-pct`，改由页面用导出的 `restPctLabel(ratio)` 算好、放进新的
  `.usage-copy` 右列。
- 「退出登录」**不归任何组**（页面注释里那条规矩照旧：它是"离开这一页"，不是这一页
  上的一项设置）——只把它收进 680 版心的流里，不再孤悬。

## 二、体检六件 + 两处顺手（全部经控制器裁定后的口径）

| # | 做什么 | 关键决定（照这个做） |
|---|---|---|
| 1 | **落地页那句假话**：`LandingPage.tsx:314-315`「点哪一句就回到哪一步」（该交互 10-06 已退役） | 改成描述照片上方那圈转盘。新文案见 plan Task 4。**「回到这一步」作为能力名保留**（只在 `StepStrip` 的 aria-label 里）；门面不再用它当标题 |
| 2 | **「打不开」标准件**：三页错误态从"左上角红字 + 空话"改成**居中一句 + 一颗「再试一次」**（和空态同一副样子） | 新组件 `ui/kit/ErrorState.tsx`；三页各自的 fetch 重跑一次就是"再试一次"；「刷新一下页面，再试一次。」这句**退役** |
| 3 | **404 分流 + 未知网址页** | ①详情页 404（`code 404`）→「这张作品不在了。」+「回作品」按钮，不再劝人刷新；②认不出的网址 → 新的 `notfound` 视图（`view.ts`），地址栏**不改写**，页是「没找到这一页」+ 回修图 / 看产品介绍 |
| 4 | **路由失败挂「再试一次」**：`App.tsx` catch 里 `say(errorText(...))` 一分钱都没挂按钮 | 复用 ChatPanel 现成的重试按钮形状；点了**原样重发同一句话**（现场只存那句原文） |
| 5 | **「下载」统一名字**：`Banners.tsx:92`「下载到电脑」、`WorkDetailPage.tsx` 下载按钮「下载到我的电脑」→ 全叫「下载」 | 文案规范名字表同步（那两处原先是漏网的） |
| 6 | **两行可达性**：`Nav.tsx` 的导航项补 `aria-current="page"`（含人物图标那颗）；`Banners.tsx` 通知条根元素加 `role="status"` | 忙态气泡**不加** aria-live（秒表每秒变化会把读屏刷屏）——**有意不做，别再当漏项** |
| 附 | `styles.css:63-64` 色号表那句「深蓝」→「深青（薄荷深档）」；模型设置页头加「← 个人设置」面包屑（和作品详情「← 作品」同一副样子）；作品页空态补一颗「去改一张」（和对话列表空态同款，撤掉指方位的文字） | — |

## 三、显式不做（裁定，别再捡回来）

- **设置页不加"我的预设 / Lut"索引格**：体检建议过，但 ① Lut 的重复入口是用户
  2026-10-06 亲自撤掉的（「同一件事的入口只有一个出处」）；② 「我的预设」管理没有
  独立落点（住在调色面板头，没照片到不了）——加了只会是一个点不动的格子。
- **忙态 aria-live**：见上表 #6。
- 体检报告里的两条假阳性（`.lp-rise` 截图空白、探针误拦 `/src/api/works.ts`）不修。
