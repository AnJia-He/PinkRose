# HDR 合成设计 —— 2026-10-18

## 目标

给 Web 修图产品补上多曝光 HDR 合成：从本地选同一场景的 2–5 张不同曝光
照片，本机融合成一张暗部和亮部都保住细节的照片，并直接下载。不调用模型，
不增加一级导航；入口放在「作品」页头，和全景、拼图并列。

## 对齐

- 每张缩到高 72px 的灰度图。
- 以中间一张为参考，在 ±3% 范围内逐像素搜索平移；用归一化互相关
  比较，整体明暗差不会把结果带偏。
- 只在相关系数 ≥ 0.35 时采用；低置信度直接不动，不做硬猜。
- 只做平移，不做旋转 / 透视；文案明确说「自动对齐轻微手抖」。

## 曝光融合

- 每张按目标高度重绘并应用平移。
- 逐像素权重 = 曝光适中度² × 局部反差 × 饱和度；权重归一化后融合。
- 输出保持原图比例；总像素上限 16 MP，超过时等比降低高度。
- 风格：
  - 自然：融合结果原样输出；
  - 鲜明：轻反差 + 轻饱和；
  - 戏剧：更强反差 + 轻饱和。

## 导出

- JPG / PNG / WebP；JPG / WebP 质量 60–100。
- 高度：1200 / 1600 / 2000。
- 文件名：`PinkRose-hdr-YYYYMMDD-HHmm.<ext>`。
- 显示解码 / 合成进度，可停止；取消或异常时关闭所有 `ImageBitmap`。

## 验收

- `image/hdrMerge.test.ts`：暗部提亮、高光不爆、风格变化、平移估计、尺寸、文件名。
- `ui/HdrPanel.test.tsx`：至少两张才能生成、风格 / 对齐参数传递、下载与再下载。
- `App.gallery.test.tsx`：作品页进入 HDR、返回作品页。
- 真浏览器（Chromium + WebKit）：三档曝光预览、风格切换、成片尺寸与明暗细节、
  390px 不横向溢出、控制台无错误。
