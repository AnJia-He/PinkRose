# 涂鸦画笔设计 —— 2026-10-18

## 目标

在「装饰」工具里补自由涂鸦：用户直接在照片上画线，选颜色、笔刷粗细和
不透明度，支持撤销一笔 / 清空；应用后写进当前这一版底图，可撤销。
不新增一级工具格，不挤窄屏。

## 坐标与预览

- 笔画点全部是 0~1 的归一化坐标，相对照片可见矩形。
- 预览层 `DoodleOverlay` 和成片 `image/doodle.ts` 共用 `drawDoodle`。
- 笔刷直径 = 照片短边 × `sizePct / 100`；预览按盒子短边算，成片按照片短边算。
- 预览画布按 devicePixelRatio 放大，最多 2×，保持线条清晰。
- 指针拖动挂在 window 上：拖出照片再回来继续画；松手才提交一整笔。

## 交互

- 第二行：边框 / 贴纸 / 叠加 / 涂鸦 + 颜色 / 笔刷 / 不透明度 +
  撤销一笔 / 清空 + 取消 / 应用涂鸦。
- 没画过时「应用涂鸦」禁用；强度 0 不允许出现（不透明度下限 10）。
- 撤销只移除最后一笔；清空移除全部，现场保留，用户可以继续画。

## 验收

- `image/doodle.test.ts`：短边笔刷、归一化坐标、单点圆点、空笔画、透明度钳制。
- `App.tools.test.tsx`：装饰 → 涂鸦 → 画一笔 → 撤销 / 再画 → 应用后换底图。
- 真浏览器（Chromium + WebKit）：画一笔后应用按钮可用，撤销后禁用；
  应用后底图出现红色笔画；390px 第二行可横滑且页面不横向溢出。
