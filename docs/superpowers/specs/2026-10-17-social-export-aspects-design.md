# 社交比例导出（设计）— 2026-10-17

## 0. 一句话

导出设置新增「比例」：原图 / 1:1 / 4:5 / 3:4 / 9:16 / 16:9。选择非原图比例时，
可以居中裁切，也可以保留完整画面、用模糊或镜像扩展画布，再按所选长边输出，
方便直接发朋友圈、小红书、短视频封面等。

## 1. 尺寸规则

- 居中取最大目标比例区域，裁切框不越界；
- 扩展模式只补画布，不裁原图；模糊扩展用原图放大虚化铺底，镜像扩展再补四边镜像；
- 选社交比例时允许放大到目标长边（例如 800×800 裁完选 1080 → 1080×1080）；
- 选「原图」比例时保持旧规则：只缩小、不放大；
- 格式、质量、透明处理仍沿用现有导出链；
- 只作用于下载 / 分享，不影响存进作品集的母版。

## 2. 界面

- 「导出设置」里新增一排比例 radio；
- 选了非原图比例后，再显示「方式」：裁切 / 模糊扩展 / 镜像扩展；
- 桌面和 390px 手机都不横向溢出；
- 批量处理暂不显示比例行，保持原批量行为；单张导出先支持。

## 3. 验证

- `export/save.test.ts`：各比例居中裁切、社交比例允许放大；
- `ui/ExportSettings.test.tsx`：比例 radio 交给上层；
- 真浏览器：1:1 + 1080 下载文件实际为 1080×1080，手机设置面板在屏内。

## 4. 不做

- 不做智能主体重构图 / AI 扩图；
- 不动小程序。
