# 可回改文字层设计 —— 2026-10-19

> 2026-10-19 当天扩展：同一套 `EditLayer` 现在也承载**形状层**
> （`{ kind:'shape', id, options }`）和**贴纸层**
> （`{ kind:'sticker', id, options, image? }`）。文字 / 形状 / 贴纸共用账本、
> 会话 `steps[].layers`、封面合成、导出合成和几何合并；区别只在渲染器与各自的控制面板。
> 自定义图片贴纸的 `image` 是 512px 内的透明 PNG data URL，导出 / 封面 / 恢复前
> 预解码到运行时缓存。

## 目标

文字从“应用一次就烤进底图”改成**非破坏式文字层**：

- 同一版可以叠多层；
- 点已有层回来改内容 / 字体 / 颜色 / 位置 / 旋转 / 行距 / 字距；
- 单独删除一层，仍可撤销；
- 刷新 / 恢复会话后层还在；
- 导出、分享、存作品、封面时才把层合成进成片。

底图像素始终不因写字而改变，这是和裁剪 / 点修 / 磨皮那类破坏式编辑的分界。

## 数据形状

```ts
type TextLayer = { id: string; options: TextOptions }
```

`TextOptions` / 归一化 / 字体栈从 `src/image/text.ts` 抽到 `shared/text.ts`，
前端画布、会话落盘和恢复共用同一份契约。位置 `(x, y)` 仍是归一化中心点，
字号仍是图片像素。

外层限制：单层最多 2000 字、一版最多 40 层；坏层只丢那一层，不拖垮整条会话。

## 账本与历史

- `Snapshot.layers?: TextLayer[]`、`EditState.layers?: TextLayer[]`；
- 缺席 = 老数据 = 没有文字层；
- `sameEdit` 比较层数组（id + 归一化 options），净零不记账；
- 文字层的提交走 `applyLayersEdit`：不换 base、不推 `baseSeqRef`、不重传底图，
  只记一笔账并把 `layersChanged` 标给落盘；
- `上一步 / 下一步 / 回到这一步` 和参数 / 滤镜一样还原文字层。

## 会话落盘

- `SessionStep.layers?: TextLayer[]`；
- 顶层 `SessionPatch.layers` 和 `params` / `lut` 同一条状态路，
  落在 `stateStepId` 指名的那一步；
- 显式 `[]` = 清空该版文字层；不带键 = 这次不表态；
- 服务端 steps 仍是 JSON 列，**不需要数据库迁移**；
- 封面和步骤小图会先把文字层合成到画布副本，再缩略，避免列表上看不到字。

## 显示与导出

- `Canvas` 用只读 `TextOverlay` 画已提交层，正在编辑的那层从已提交列表里拿掉，
  避免重影；
- 导出在裁切 / 扩画布之后、缩放 / 水印之前合成：
  - 原比例：直接复制画布并画层；
  - 居中裁切：按 `-crop.x / -crop.y` 平移；
  - 模糊 / 镜像扩展：按扩展后的照片偏移 `dx / dy` 平移。

## 已知边界

- 文字层和底图一起按版本存储，但**作品配方不携带文字层**：
  “套配方到另一张照片”只套调色 / 滤镜，不把上一张图的文案搬过去。
- 裁剪 / 透视 / 扩画布 / 加边框 / 超清放大 / AI 扩图会先合并文字层再动像素，
  并在新版本里清空层；撤销该操作会连文字层一起回来。
- 恢复会话时步骤小图会尽量合成文字层；没有离屏 2D 上下文时退回底图直出，
  主画面和导出仍以 `layers` 为准。
