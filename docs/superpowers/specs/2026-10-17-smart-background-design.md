# 智能主体与背景替换（设计）— 2026-10-17

## 0. 一句话

在现有「点修 → 抠图」里补两项：**智能主体**自动估出背景选区，以及把背景换成
白底 / 蓝底 / 灰底 / 虚化原背景 / 自定义颜色 / 自定义图片。全部在本机完成，
不调用模型，不新增依赖。

## 1. 为什么放在抠图里

现有抠图已经有正确的三件基础设施：

- 0–255 背景覆盖率掩码，255 = 去掉；
- 画笔 / 橡皮修边；
- `baseEdit` 的新底图、账本、撤销和落盘。

「智能主体」只是换一种方式填这张掩码；「换背景」只是换一种方式消费这张掩码。
另起工具会复制同一套代码，也会让用户以为这是两个互不相干的功能。

## 2. 智能主体

不冒充神经网络分割，文案叫「智能主体」，实现是**本地前景估计**：

1. 将照片缩到长边 ≤ 640 再计算，避免 12 MP 照片卡住主线程；
2. 从顶部和左右上缘采样背景色，做确定性的 4 色聚类；
3. 每个像素取到最近背景色的距离，用 Otsu 阈值分开背景与候选主体；
4. 只从画面边缘向内洪泛和背景色连通的区域，主体内部的洞不会被误删；
5. 按连通域面积和画面中心位置去掉边缘碎块；
6. 在低分辨率掩码上做一次软边模糊，再双线性放大回原图；
7. 主体占比 < 2% 或 > 95% 时明确提示「没分出来」，不乱改画面。

结果直接写进现有背景掩码，用户可以继续用画笔补回头发、擦掉残留背景。

## 3. 背景替换

背景选择：

| 选项 | 成片 |
| --- | --- |
| 透明底 | 保留 alpha；PNG / WebP 透明，JPG 导出时铺白 |
| 白底 / 证件蓝 / 浅灰 | 纯色合成 |
| 虚化原背景 | 原图先高斯虚化，再叠回主体 |
| 自定义颜色 | 原生颜色选择器 |
| 自定义图片 | 图片按 cover 铺满，再叠回主体 |

主体边缘使用掩码的软覆盖率先压 alpha，再合成到新背景。输出仍是当前这一版的
新底图，记一笔账，可撤销；不推转盘格、不写对话、不花模型额度。

## 4. 界面

仍在「点修 → 抠图」第二行：

- 修补（返回）/ **智能主体** / 点背景 / 画笔 / 橡皮 / 笔刷 / 容差；
- **背景**下拉：透明底、白底、证件蓝、浅灰、虚化原背景、自定义颜色、自定义图片；
- 选自定义颜色时露出颜色选择器；选自定义图片时露出选图按钮和文件名；
- 主按钮文字随背景变化：「擦成透明」或「换背景」；
- 还没选区、正在识别、正在合成、自定义图片还没选时，主按钮禁用。

窄屏沿用现有第二行横向滚动，不压缩照片高度。

## 5. 错误与边界

- 主体识别太快撞到极端比值：保留现场，提示点背景或手动画；
- 自定义图片解码失败：不退出抠图，提示换一张；
- 底图在异步识别 / 合成期间被生成或跳版本替换：沿用 `discardStaleBaseEdit`，
  这一下作废，不写错版本；
- 大面积识别仍走现有暗罩与面积闸；
- 自定义背景位图在取消、完成、换图时 `close()`，不泄漏 GPU 内存。
