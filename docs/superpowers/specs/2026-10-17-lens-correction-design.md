# 镜头校正设计 —— 2026-10-17

## 目标

补上手机广角、运动相机和转接镜头常见的两类修正：

1. **畸变校正**：把桶形 / 枕形弯曲的直线拉回来。
2. **色差校正**：把画面边缘的红 / 青色边轻轻收拢。

两者都作为调色参数进入现有渲染管线，可存预设、进作品配方、在会话中恢复。
小程序本轮不改 UI；共享参数、着色器和 uniform 同步过去，旧作品默认 0 仍保持原样。

## 参数

- `lensDistortion`: `-100~100`，0 = 不校正。
  - 正值按“桶形画面向外鼓起”的方向校正，负值按相反方向校正。
  - 采样网格做径向二次映射；正向会把采样推到画面外，因此自动计算统一缩放，
    四角始终落在 `[0,1]` 内，不留空边。
- `lensChromatic`: `-100~100`，0 = 不校正。
  - 只把红、蓝通道沿径向做相反方向的小位移，绿色保持不动。
  - 最大值约 4~5 个像素（按纹理尺寸归一化），只够收掉边缘色边，不改变构图。

两项追加在 `PARAM_KEYS` 末尾，老参数顺序不变；面板新增「镜头校正」组，
和「镜头」里的径向虚化分开。

## 渲染

采样坐标顺序：

```
输出坐标 → 透视校正 → 镜头畸变校正 → 读取纹理
```

镜头畸变的 0 分支直接返回原坐标，和加功能之前逐像素相同。
色差为 0 时只采样一次，和普通单点采样相同；非 0 时额外采样红、蓝两个位置。
暗角、径向虚化仍使用输出坐标 `vUv`，不会跟着采样网格弯掉。

- `render/uniforms.test.ts`：两个新 uniform 的映射。
- `render/shader.test.ts`：0 早退、采样顺序、色差使用红蓝通道、输出坐标效果不弯。
- `npm run check:lut`：真实 Chromium + GPU，确认着色器真的编得过。
- 浏览器网格图：畸变改变边缘直线位置；色差让红 / 蓝通道边缘分离或收拢；
  0 时与基线一致。
