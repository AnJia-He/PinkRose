# 局部黑眼圈 —— 2026-10-18

## 目标

补齐人像修图里的高频项「去黑眼圈 / 轻度眼袋」。沿用「局部」现有的
涂抹蒙版、强度、账本和撤销链路，不新增可回编辑图层，也不改动全局参数。

## 像素算法

- 只在掩码内计算；覆盖率为 0 的像素一个字节都不写。
- 用同一块掩码的可分离盒式模糊估「周围肤色」亮度，参考半径取短边的
  0.65 倍（夹在 3~64 px），避免深肤色被整块误判为黑眼圈。
- 只处理比参考暗 2~28 级以上的像素；往参考亮度走 55%，保留自然阴影。
- 暗沉常带蓝紫：把高于红绿平均值的蓝压回 45%，并给 2% 暖调。
- 模糊只用于算参考，输出仍按原像素比例提亮，皮肤纹理不被抹平。

## 自动选区

- 正脸框内，眼睛中心按 30% / 70% 宽、42% 高估计。
- 眼下椭圆中心在 56% 高，横向 17% 宽、纵向 7% 高；上缘不碰眼球，
  边缘用 smoothstep 留软过渡。
- 用户仍可用画笔补涂、橡皮修回；找不到正脸时提示手动画笔。

## 验收

- 单测：选区位置与软边、暗沉提亮、蓝紫回收、正常肤色与掩码外不变、
  强度 0 恒等。
- App：点「自动眼下」后掩码非空、主按钮可按，提交
  `{ effect: 'darkcircle' }`，全局参数保持 ZERO，不进转盘。
- 390px / iPad / WebKit：控件不撑破布局，控制台无错误。
