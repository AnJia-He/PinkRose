# 实时直方图（设计）— 2026-10-18

## 0. 一句话

调色面板顶部新增实时 RGB 直方图和暗部 / 高光溢出读数。数据来自同一套
着色器在 128×128 离屏缓冲上的渲染结果，和眼前看到的大图一致；不改变照片像素。

## 1. 为什么是它

Lightroom、Snapseed、VSCO 的调色面板都有直方图。产品现在有 74 个参数，
用户需要一个「亮部有没有爆、暗部有没有死黑」的总览。直方图是纯读数，
不影响成片，也不占参数位。

## 2. 数据

- `TonePipeline.readHistogram()`：绑定 128×128 FBO，用同一 program / uniform
  再画一遍，`readPixels` 后交给纯函数 `computeHistogram`；
- 三条通道各 64 柱，每条通道除以自己的最高柱，再开平方，低柱也看得见；
- `shadowClip` / `highlightClip`：三通道都 ≤4 / ≥251 的像素比例；
- 直方图只在小离屏缓冲上取样，屏幕默认 framebuffer 仍是正常那一帧。

## 3. 界面

- 直方图放在调色面板头下方、「照着这张调」之前；
- 三条线用 R / G / B 内容色（不是主题强调色）；
- 下方显示「暗部 x%」「高光 x%」；超过 0.5% 时用 `--danger` 标出；
- 还没画完时显示「等画面画完…」，不画假线。

## 4. 性能

- 只在调色屏传 `onHistogram`；别的屏不读回；
- 128×128 = 64KB / 次，FBO 离屏渲染和主画面同一套 uniforms；
- 读不回来只关掉直方图，不影响主画面。

## 5. 验证

- `render/histogram.test.ts`：通道、归一化、溢出、空输入；
- `ui/Histogram.test.tsx`：三条线、读数、空态；
- 真机 Chromium + WebKit：黑白灰三条色带 → 暗部 / 高光约 33%，调亮度后
  直方图路径实时变化，390px 不溢出，控制台无错误；
- `npm test`、typecheck、build、check:layout、check:copy、check:safari。

- 不做波形图 / 矢量示波器；
- 不改小程序界面。
