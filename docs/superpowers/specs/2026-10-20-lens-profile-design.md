# 镜头配置文件设计 —— 2026-10-20

## 目标

补上市面修图产品常见、但之前只有三根手动滑杆的一项：**按照片 EXIF 认出镜头，
给出畸变 / 暗角 / 色差的一组校正起点**。本地计算，不上传照片，不依赖新服务；
苹果端和桌面端走同一套 UI。

## 数据与匹配

- `src/core/photoInfo.ts` 新增 `readLensInfo(file)`：只读 JPEG EXIF，返回
  机身、镜头、焦距的原始字段；同一份文件按 `name:size:lastModified` 缓存。
- `src/core/lensProfile.ts` 内置 15 套常见配置（Sony / Canon / Nikon / Fujifilm /
  Sigma / Tamron / iPhone 主摄）。每条配置有：
  - `lensPatterns`：镜头型号规范化后必须全部命中的子串；
  - `cameraPatterns`：镜头字段缺失时按机身认固定镜头相机；
  - `focalRange`：变焦镜头的焦段范围；
  - `distortion` / `vignette` / `chromatic`：定焦给一个数，变焦给
    `[广角端, 长焦端]`，按实际焦距线性插值。
- 认不出来返回 `null`，不硬套。手动选择永远可用。

## 数值口径

数值是**校正方向**的起点，不是镜头缺陷的测量值：

- 广角变焦的桶形更明显，畸变校正给得更强；长焦端递减。
- 暗角按广角端更明显、长焦端更轻处理。
- 色差只给很小的起点（手机通常已在机内校正）。
- 所有值钳在 `-100~100`，和现有三根滑杆完全同一口径。

内置值是近似起点，套用后仍可拖滑杆微调；UI 明写这一点，不把它说成官方标定。

## UI

`ui/LensProfilePicker.tsx` 住在调色面板「镜头校正」组的最上面：

- 自动读取 EXIF，显示「已识别 / 未收录 / 手动选择」和匹配到的镜头名；
- 下拉列出全部内置配置；
- 点「套用配置」才把三条值写进当前参数（**不自动覆盖**用户已经手调过的值）；
- 套用后按钮变「已套用」，三根滑杆仍可继续调；
- 恢复会话、没有原文件时仍能手动选。

### 我的配置

内置库之外的冷门镜头（转接环、电影镜头、老镜头）可以：

- 把当前三根校正值按一个名字存进本机 `localStorage`；
- 保存时同时记下当前照片的镜头型号 / 机身型号，下次同一支镜头按 EXIF 自动认回来；
- 在「我的配置」分组里再次套用或删除；
- 批量页按 EXIF 自动镜头校正会优先使用自定义配置（同名覆盖，最多 20 条）。

只存名称、型号和三个数值，不上传照片，也不进云端账号。

## 批量

批量页的调色区新增「按 EXIF 自动镜头校正」开关：

- 每张照片按自己的 EXIF 认镜头，认出的照片覆盖畸变 / 暗角 / 色差三根；
- 认不出的照片保留用户在批量页选的校正值，不会因为一张失败影响整批；
- 结果区报告实际套用了几张、几张没认出镜头。

## 验证

- `core/lensProfile.test.ts`：Sony / Canon / Nikon / Fujifilm / iPhone 匹配、
  未知镜头返回 null、变焦插值、所有值在范围内且不碰别的参数。
- `core/photoInfo.test.ts`：原始镜头字段读取。
- `ui/LensProfilePicker.test.tsx`：识别后套用、未知镜头手动选、无原文件仍可用。
- `npm run check:lens`：WebKit 真浏览器，带 Sony EXIF 的 JPEG 走
  「识别 → 套用 → 三根滑杆值 → 画面变化 → 390px 布局 → 手动换一支」8 条。

## 不做

- 不做按机身 + 镜头 + 焦段 + 光圈的四维标定数据库；那需要实测数据。
- 不做联网下载官方配置文件。
- 不改现有三根滑杆的参数顺序和渲染管线；镜头配置只是它们的起点。
