# 局部发色设计 —— 2026-10-18

## 目标

在「局部」工具里补一个高频美颜能力：用户先用手动画笔涂出头发，再从
自然黑 / 深棕 / 亚麻 / 酒红 / 雾蓝 / 玫瑰金里选一个色号，应用后只改
当前这一版底图的头发区域。不调用模型，不写全局参数。

## 为什么手动画

头发和深色背景、眉毛、阴影经常粘在一起；本地肤色 / 人脸框能估脸，
但估不准发丝边界。第一版明确做「先涂再换色」：

- 用户看得见蒙版，溢出能立刻用橡皮修；
- 不承诺自动识别头发，文案也不暗示；
- 和牙齿 / 亮眼 / 红眼走同一条局部账本，行为一致。

## 换色算法

- 对掩码内每个像素取原亮度 `l` 和目标色的中间调亮度 `tl`；
- 目标色按 `(l + 10) / (tl + 10)` 缩放，再按覆盖率 × 强度混回原像素；
- `+10` 是暗部保险：纯黑头发也能看出一点色相；
- 缩放而不是直接覆盖，保住发丝暗部、高光和体积感；
- 掩码外逐字节不变；强度 0 为恒等。

## 色号

- 自然黑、深棕、亚麻、酒红、雾蓝、玫瑰金。
- 色板只在「发色」模式出现，选中项有 `aria-pressed`。

## 验收

- `image/localAdjust.test.ts`：掩码外不动、发色偏红、亮度结构保留、强度 0 恒等。
- `App.tools.test.tsx`：涂过 + 选酒红 + 应用，提交 `{effect:'hair', hairShade:'wine'}`。
- 真浏览器（Chromium + WebKit）：涂头发 → 选酒红 → 应用后头发 r-g 明显上升，
  皮肤区域 0 变化；390px 第二行可横滑且页面不横向溢出。
