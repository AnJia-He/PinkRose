# 批量水印（设计）— 2026-10-17

## 0. 一句话

「作品 → 批量处理」新增批量水印：一套文字水印，可选位置、透明度和字号，
在每张照片调色完成后、编码前画上，随现有 ZIP 一起下载。全部本机完成。

## 1. 像素

- 字号按短边百分比计算（1~12%，默认 4%）；
- 位置：右下 / 左下 / 右上 / 左上 / 居中；
- 白色文字 + 深色阴影，透明度 10~100%（默认 70%）；
- 文字留空 = 完全不画，一个字节不写；
- 仍走每张照片的现有链路：解码 → 缩放 → WebGL 调色 → 水印 → EXIF 写回 / 编码。

## 2. 界面

- 批量页「调色」与「导出」之间新增「水印」；
- 输入文字后出现位置下拉、不透明度、字号滑杆；
- 手机单列，不横向溢出；
- 修改水印会清掉上一批结果，避免把旧 ZIP 当新结果。

## 3. 验证

- `image/watermark.test.ts`：右下 / 居中 / 左上定位、字号边界；
- `batch/process.test.ts`：传了水印时逐张调用绘制；
- `BatchPanel.test.tsx`：输入文字后提交给批量处理；
- 真浏览器：水印像素真画出白字，手机批量页不溢出、无控制台错误。
