# 人像美妆：口红 / 腮红（设计）— 2026-10-17

## 0. 一句话

「人像」工具在瘦脸 / 大眼 / 下巴 / 瘦身之外，再加**口红**和**腮红**两根
0–100 滑杆，以及珊瑚 / 玫瑰 / 莓果三档口红色号。先在本机预览，点
「应用人像」才写进当前底图；不调用模型、可撤销。

## 1. 为什么是它

醒图、美图秀秀、轻颜这类人像产品的「美妆」是高频入口；现有产品已经有
磨皮、美白 / 红润、瘦脸 / 大眼 / 下巴 / 瘦身，缺的正是嘴唇和脸颊这两块
最直观的彩妆。它和现有美颜同属本地像素操作，不依赖新模型或新纹理。

## 2. 像素规则

### 2.1 嘴唇

- 先在脸框下半部找「像嘴唇」的像素：饱和度明显高于嘴周阴影，且偏红；
- 用 5×5 平滑后的最大权重定位嘴部，再取局部红色区域的外接框中心，
  不用整块下半脸的重心 —— 脸框常把脖子一起框进来，重心会落到下巴；
- 以该中心放一个软边椭圆（宽约 0.44w、高约 0.16h），椭圆内再用
  `lipness` 颜色门：高饱和红唇 / 低亮度的重色唇留下，暖肤色、牙齿、
  嘴周阴影压掉；
- 用「保持原亮度、替换色相 / 饱和度」的方式混色，强度上限 0.5，
  三档色号的 RGB 分别来自 `LIP_SHADES`。

### 2.2 腮红

- 两颊各一个软边椭圆（中心在脸框 30% / 70%、高度 62%）；
- 用 Cb/Cr 肤色门，只给皮肤上色；强度上限 0.18，避免「猴屁股」；
- 保持原亮度，只加一点血色。

### 2.3 恒等

- 口红 / 腮红都是 0 时，`makeupPixels` 直接返回 `changed: 0`，一个字节不动；
- alpha 永远不碰；
- 只扫描嘴唇 / 两颊椭圆的并集外接框，不整图扫。

## 3. 交互

- 人像第二行新增「口红」「腮红」滑杆；
- 口红 > 0 时出现三个色号小胶囊：珊瑚 / 玫瑰 / 莓果；
- 滑杆变化走现有 120ms 防抖预览：先 `faceShapeToBitmap`，再
  `makeupToBitmap`；应用时按原尺寸重算同一条链；
- 仍然只改当前这一版底图、账本记一笔、不推转盘格、不写对话、不花模型额度；
- 找不到正脸时沿用现有提示，不自动硬涂。
