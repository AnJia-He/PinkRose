# 相连区域选择设计 —— 2026-10-21

## 背景

现有「色彩范围」会选中整张图里所有相近颜色。用户点一件衣服时，另一侧同色物体
也会被一起选中。主流局部修图需要“只选这块连着的区域”，因此增加相连生长模式。

## 交互

- 「局部 → 色彩范围」增加「相连区域」开关。
- 开关关闭时保持原行为：全图同色像素都进入蒙版。
- 开关开启后，点照片上的颜色，只从点击像素四邻向外生长，不跨过颜色不相近的区域。
- 容差 / 羽化 / 反选 / 扩边继续可用；调整参数时使用同一个点击种子重算。
- 存成局部层时，`connected` 和归一化种子 `[x, y]` 一起保存，回来仍能继续调整。

## 实现

- `core/colorRange.ts` 先按原 HSV 判据生成全图覆盖 mask，再在开启相连时做四邻 BFS，
  只保留从点击种子可达的部分。
- `LocalColorRange` 增加可选 `connected` / `seed`；旧数据没有这两个字段时保持全图模式。
- 点击种子归一化到 0–1，并限制在 0–1 内存储。
- 仍是本地纯像素计算，不调用模型。

## 验证

- `src/core/colorRange.test.ts`：左右同色但不连通的块，点左只选左、点右只选右。
- `shared/layers.test.ts`：相连参数和种子可持久化，换种子算图层变化。
- `src/App.tools.test.tsx`：切换相连模式、点击种子进入 mask、存层保留参数。
- `npm run check:connected-select`：WebKit 390px；左侧变、右侧不变，无溢出、控制台无错误。
