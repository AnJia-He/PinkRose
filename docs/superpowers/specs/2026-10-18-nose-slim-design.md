# 瘦鼻设计 —— 2026-10-18

## 目标

在「人像」工具里补第五根塑形滑杆：把鼻梁两侧向中线收，收窄鼻翼。
沿用本地肤色估计的正脸框，不引入关键点模型；0 = 不动，100 = 最大收窄。

## 几何

- 鼻区中心在脸框高度的 58%，半宽为脸宽的 18%，半高为脸高的 13%。
- 输出像素落在鼻区椭圆内时，向鼻翼外侧取样再映回原位：`srcX = cx + (x - cx) * scale`。
- `scale = 1 + 0.6 × 强度 × falloff`；falloff 从中心向外平滑淡出，
  鼻尖 / 鼻翼边缘不硬切。
- 只改鼻区采样，眼、嘴和脸框外不受影响；脸框边缘继续走原有的径向淡出。

## 验收

- `image/faceShape.test.ts`：鼻翼一侧的竖线向中线收，脸外逐字节不变。
- `App.tools.test.tsx`：人像第二行有「瘦鼻」，预览 / 应用都收到 `nose` 值。
- 真浏览器（Chromium + WebKit）：合成正脸左右两条鼻梁线都向中线靠，
  应用成片同样收窄；390px 第二行可横滑且页面不横向溢出。
