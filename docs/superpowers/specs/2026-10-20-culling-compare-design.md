# 全屏选片对比设计 —— 2026-10-20

## 0. 背景

摄影师挑连拍时经常要在两张近似照片之间比较。原来的全屏看片一次只看一张，
只能来回按方向键切换，很难判断表情、焦点和构图的差别。

## 1. 交互

- 全屏看片顶栏新增「对比」按钮，快捷键 `C`；
- 进入后当前照片作为底图，默认叠加下一张（循环）；
- 底部滑杆控制左右分割位置，`[` / `]` 换对比图；
- `0–5` 评分、P/X/U 标记仍然作用于当前照片；
- 对比时退出 1:1 缩放，避免两个滚动容器互相打架；只有一张作品时按钮禁用。

## 2. 实现

- 两张图都使用 `object-fit: contain` 放在同一个舞台盒里，保证同一块画面区域
  在分割线两侧对齐；
- 上层图用 `clip-path: inset(0 0 0 split%)` 裁出右侧，底层图自然露出左侧；
- 顶栏左右角显示当前 / 对比照片的日期或名字。

## 3. 验证

- `CullingLightbox.test.tsx`：C 进入 / 退出、两张图、分割滑杆、`]` 换图；
- Chromium 实测两张作品进入对比，显示 2 张图、分割滑杆 0–100，页面无横向溢出；
- 对比只改变查看方式，不修改评分、标记或照片字节。
