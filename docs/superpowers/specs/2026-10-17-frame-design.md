# 边框工具（设计）— 2026-10-17

## 0. 一句话

工具行补上「边框」：纯色 / 拍立得 / 胶片 / 圆角四种样式，宽度和颜色可调，
照片上实时预览，点「应用边框」写进当前这一版的底图、账本记一笔、可撤销。

## 1. 为什么做边框

市面上的消费修图产品普遍把「边框 / 相框」当作独立工具：

- 社交平台发图前加白边 / 拍立得；
- 胶片风格要上下黑边和齿孔；
- 圆角照片用于头像 / 卡片。

它不需要新的数据模型：产出新底图即可复用 `app/baseEdit.ts` 的裁剪 / 点修 /
磨皮 / 文字同一条骨架。边框宽度按**短边百分比**算，横竖图看起来一样粗。

## 2. 样式

```
solid     纯色四边
polaroid  上 / 左右同宽，下边 2.5 倍（拍立得）
film      只压上下两条（1.4 倍边宽）+ 齿孔
rounded   四边 + 照片圆角
```

选项：

```ts
type FrameOptions = { style: FrameStyle; color: string; widthPct: number }
```

- `widthPct` 0~20，占短边百分比；
- 颜色只认 `#rrggbb`；
- `frameFractions` 是预览和成片**共用的唯一公式**；
- `frameLayout` 给出像素照片矩形和圆角半径。

## 3. 界面

- 工具行第七颗「边框」，图标 `Frame`；
- 第二行：四个样式药丸 + 宽度 + 颜色 + 取消 / 应用边框；
- 照片上是 `FrameOverlay` 画四条边（film 用重复渐变画齿孔）；
- 窄屏七颗工具格收紧内边距，第二行横滑。

## 4. 不做什么

- 不做贴纸 / 手绘边框；
- 不做自定义相框图片导入；
- 不做圆角预览的精确裁切（应用后成片准确）；
- 不动小程序界面。

## 5. 验证

- `image/frame.test.ts`：选项夹取、四边比例、拍立得 / 胶片、像素布局；
- `App.tools.test.tsx`：预览现场 → 应用 → 换底图、收工具、不进转盘；
- `ToolBar.test.tsx`：七颗工具格；
- `check:layout`：「开着边框」第二行与七颗工具格在 390px 内；
- 真浏览器：四种样式预览 / 应用后的像素边宽和颜色。
