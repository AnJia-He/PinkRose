# 形状工具设计 —— 2026-10-19

## 目标

在「装饰」工具里补一个形状入口：矩形、椭圆、直线、箭头。用户在照片上
直接拖出两个端点，再调线宽、圆角、描边色、填充色和整体不透明度。

## 契约

- 坐标是 0~1 的归一化端点 `(x1,y1)`、`(x2,y2)`；线宽和圆角按照片短边
  百分比算，同一套设置在 2 MP 和 24 MP 上观感一致。
- 预览和成片共用 `image/shape.ts` 的 `shapeDrawing()`，不各写一套几何。
- 提交走 `app/baseEdit.ts`：只改当前这一版底图、账本记一笔、可撤销；
  不进转盘、不写对话、不碰 `params`。
- 箭头头部用描边色填充；矩形 / 椭圆可单独开关填充，填充色和填充度可调。
- 0 = 什么都不画；应用后工具收掉，和贴纸 / 边框 / 文字同一套手感。

## 不做

- 不做多形状对象列表 / 图层重排（后续图层系统再统一做）。
- 不做任意曲线、多边形和文字路径。
- 不动小程序（本轮只改 Web）。

## 验收

- `image/shape.test.ts`：端点钳制、矩形 / 圆角 / 椭圆 / 直线 / 箭头几何。
- `App.tools.test.tsx`：装饰 → 形状 → 改椭圆 + 填充 → 应用 → 换底图、
  收工具、不进转盘。
- `ToolBar.test.tsx`：形状是装饰子模式，装饰格保持点亮。
- `npm run typecheck`、`npm run build`；真浏览器 390px 拖拽一次并确认
  控制台无错、无横向溢出。
