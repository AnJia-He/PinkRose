# 相机实时取景 100% 对焦放大镜设计 —— 2026-10-21

## 背景

相机桥已有实时取景、构图网格、对焦峰值、斑马纹、伪色、直方图和
1× / 2× / 4× 数字放大。数字放大会改变整个取景画面，不适合同时观察
构图和确认焦点。专业遥控拍摄通常另外提供一个 100% 放大镜，只放大点击位置附近。

## 交互

- 「实时取景放大」组新增 `100%` 按钮。
- 开启后，右下角出现独立放大镜；主取景画面继续保持原构图。
- 在 1× / 2× / 4× 下都能点主画面移动观察点；放大镜始终围绕该点取原生像素。
- 放大镜带中心十字线，不接收指针事件，不挡快门或主画面的点击。
- 全屏取景沿用同一放大镜，Esc 退出时一起收起。

## 采样

- `liveLoupeCrop(width, height, focusX, focusY)` 在实时取景原图上截取不超过
  `320×200` 的中心区域。
- 与普通数字变焦分开：竖幅帧不受普通变焦的 8× 上限影响，仍保证短边不超过 200。
- 截取区域按 1:1 画到放大镜画布，不做平滑拉伸，因此看到的是实时取景原生像素。

## 验证

- `src/image/liveOverlay.test.ts`：横幅居中、边界夹取、小于放大镜的帧、
  竖幅 1080×2048 的 320×200 上限。
- `src/ui/CameraBridge.test.tsx`：按钮状态、放大镜画布出现。
- `npm run check:camera-live`：模拟相机桥 + WebKit 390px；
  100% 放大镜尺寸、点击移动观察点、全屏、既有辅助线、无横向溢出、
  控制台无错误。
