# 证件照工作流（设计）— 2026-10-17

## 0. 一句话

「作品」页加「证件照」：选一张正脸照片，按一寸 / 二寸 / 小二寸 / 签证标准
尺寸自动取景、识别主体、换白 / 蓝 / 红 / 浅灰底，实时预览后下载 JPG。
全部在本机完成，不联网、不花模型额度。

## 1. 取景

- 正脸框来自本地肤色估计；
- 脸高约占输出高度 52%，头顶留约 18%；
- 按目标比例横向扩框，脸不在正中时把框收回原图；
- 没有正脸时退回居中最大目标比例区域，并靠主体识别处理背景；
- 输出直接绘制到标准像素尺寸（295×413 / 413×579 / 390×567 / 413×531）。

## 2. 换底

- 对裁好的证件照运行现有 `selectSubjectToMask`；
- 主体占比 < 2% 或 > 95% 时明确报错，不输出半成品；
- 用 `replaceBackgroundToBitmap` 换纯色底；
- 输出 JPG 95%，文件名带原图名、尺寸和底色。

## 3. 界面

- 入口：「作品」页头「证件照」；
- 单张照片，支持点击 / 拖入；
- 尺寸四选一、底色四选一；
- 改尺寸或底色后 180ms 防抖重算预览；
- 预览显示真实像素；下载按钮只在成片就绪后可按；
- 手机纵向单列，不横向溢出。

## 4. 排版打印

- 成片可再导出 6 寸相纸 `1800×1200`（300dpi）；
- 默认 4×2 八张、居中、留裁切参考线；
- 照片过大时等比缩进相纸，不拉伸；
- 下载文件名带「排版8张」。

## 5. 测试

- `idphoto/idPhoto.test.ts`：目标比例、贴边不越界、无脸居中、四套尺寸；
- `ui/IdPhotoPanel.test.tsx`：四尺寸 / 四底色 / 空态禁用下载 / 返回；
- 真浏览器：真实人像一寸白底、二寸蓝底、下载文件名、390px 布局、无控制台错误。
- 真浏览器：排版 1800×1200、八格都有内容、边缘白底。

## 6. 不做

- 不做姿态矫正、服装替换、打印排版；
- 不承诺所有侧脸 / 遮挡脸都能自动取景；
- 不动小程序。
