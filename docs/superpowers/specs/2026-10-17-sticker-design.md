# 贴纸（设计）— 2026-10-17

## 0. 一句话

把「边框」工具升级成「装饰」类，里面分「边框 / 贴纸」。贴纸内置五种矢量
形状，可拖位置、调大小、旋转和颜色；应用后写进当前底图、账本记一笔、可撤销。

## 1. 为什么放进「装饰」

边框和贴纸都是"往照片上加装饰"，共用一颗工具行格子能避免八颗格子在
390px 上溢出，也让用户在一个地方找到两类装饰。工具行显示「装饰」，
第二行用「边框 / 贴纸」切换；边框和贴纸仍各有自己的控件与提交流程。

## 2. 形状与选项

```ts
type StickerShape = 'star' | 'heart' | 'sparkle' | 'arrow' | 'speech'
type StickerOptions = {
  shape, x, y, sizePct, rotation, color
}
```

- `x/y` 归一化中心，0~1；
- `sizePct` 占短边百分比，2~60；
- `rotation` -180~180；
- 颜色只认 `#rrggbb`；
- 形状用一份 SVG path，预览 `<path>` 和成片 `Path2D` 共用，避免两套图形漂移。

## 3. 界面

- 工具行「装饰」，图标 `Sticker`；
- 边框模式第二行第一颗是「边框」（亮着），第二颗「贴纸」切过去；
- 贴纸模式第二行：边框 / 五种形状 / 大小 / 旋转 / 颜色 / 取消 / 应用贴纸；
- 照片上的贴纸可拖动，位置按归一化坐标保存；
- 窄屏继续横向滚动，出口 sticky。

## 4. 不做什么

- 不做自定义图片贴纸 / 在线素材库；
- 不做多贴纸图层（一次贴一张，重复操作可以叠）；
- 不做手势缩放 / 双指旋转（用滑杆）；
- 不动小程序界面。

## 5. 验证

- `image/sticker.test.ts`：选项夹取、布局、五种 path；
- `App.tools.test.tsx`：装饰 → 贴纸 → 心形 → 换底图、不进转盘；
- `ToolBar.test.tsx`：贴纸子模式保持「装饰」点亮；
- 真浏览器：拖位置、大小 / 旋转 / 颜色、应用后的像素和预览一致。
