# 局部眉毛设计 —— 2026-10-18

## 目标

在「局部」里补一个眉毛换色效果：用户先用手动画笔涂出眉毛，再选色号，
应用后只改当前这一版底图的涂选区域。不调用模型，不写全局参数。

## 为什么手动画

皮肤、眉骨、眉尾和周围阴影贴得很近；本地正脸框能估出脸的位置，但分不清
眉形边界。第一版明确做「先涂再上色」：用户能看见蒙版、能用橡皮修边，
不承诺自动识别眉形。

## 色号与算法

- 自然黑 / 深棕 / 灰棕 / 红棕。
- 按原亮度缩放目标色；混入覆盖率 × 强度 × 70%，保留毛流深浅和高光。
- 掩码外逐字节不变；强度 0 为恒等。

## 验收

- `image/localAdjust.test.ts`：深棕 / 红棕产生不同颜色、掩码外不动、
  强度 0 恒等。
- `App.tools.test.tsx`：涂过 + 选红棕 + 应用，提交
  `{effect:'eyebrow', eyebrowShade:'auburn'}`。
- 真浏览器（Chromium + WebKit）：眉毛区 r-g 明显上升，眉下皮肤 0 变化；
  390px 四个色号都在且不横向溢出。
