# 人像自动塑形（设计）— 2026-10-17

## 0. 一句话

工具行加「人像」：本机估出正脸框，提供**瘦脸 / 大眼 / 下巴 / 瘦身**四个滑杆，
滑杆先出预览，点「应用人像」才把结果写进当前这一版底图。

## 1. 为什么不做神经网络

本轮不增加模型权重、不下载运行时依赖，也不调用付费图片模型。人脸框用现有
肤色识别思路估计：

- 先在长边 ≤640 的副本上找画面中部最大的肤色连通域；
- 皮肤连通域常把脖子 / 胸口连进来，因此脸框高度按宽度收住；
- 只接受面积、位置和长宽都像正脸的区域；找不到就明确提示改用「局部 → 液化」。

这不是关键点检测。眼睛位置按脸框比例估计（左右 30% / 70%，高度 42%），
因此对正脸可靠，对侧脸、小脸和遮挡脸不硬猜。

## 2. 像素规则

新增 `image/faceShape.ts`，输入脸框和四个 0~100 强度：

- **瘦脸**：脸颊两侧按离中心的距离向外采样，视觉上把脸收窄；
- **大眼**：以两眼估计位置为中心做局部放大；
- **下巴**：下半张脸向中心收，并给一个很小的提下巴位移；
- **瘦身**：从脸框下方开始，向画面底部对两侧身体做软边横向收窄；脸部区域不动；
- 位移在脸框边缘平滑淡出，脸框外逐字节不变；
- 0 = 完全恒等。

算法只读脸框外接矩形 + 边距，不整图循环；预览长边 ≤1400，提交按原尺寸。

## 3. 交互

- 工具行第 4 颗「人像」（`ScanFace` 图标）；
- 打开后显示椭圆人脸框；第二行：说明 / 瘦脸 / 大眼 / 下巴 / 瘦身 / 重来 / 取消 / 应用人像；
- 滑杆 120ms 防抖出预览；
- 四个滑杆全 0 时主按钮禁用；
- 应用后换当前底图、账本记一笔、可撤销；不推转盘格、不写对话、不动全局参数；
- 识别中盖现有暗罩；大图提交同样走 `baseEdit` 的过期作废检查。

## 4. 边界

- 没找到脸：提示一句并收掉工具，不改画面；
- 侧脸 / 遮挡：提示用液化手动推；
- 预览迟到：序号不匹配直接丢弃并 close 位图；
- 取消 / 切屏 / 换照片：释放预览位图和人脸框；
- 手机：第二行横滑，照片高度不增加，应用按钮始终够得着。

## 5. 测试

- `core/faceDetect.test.ts`：正脸、无脸、边缘肤色块、尺寸错误；
- `image/faceShape.test.ts`：恒等、瘦脸位移、大眼放大、下巴只动下半脸、瘦身只动脸下方、框外不变；
- `App.tools.test.tsx`：识别 → 预览 → 提交；没脸提示；参数 / 转盘不变；
- 真浏览器：真实人像识别、预览、提交、手机 390px、无控制台错误。

## 6. 不做

- 不做 68/468 点关键点，不做自动侧脸识别；
- 不做牙齿 / 眼睛自动识别（已经有手动局部预设）；
- 不动小程序。
