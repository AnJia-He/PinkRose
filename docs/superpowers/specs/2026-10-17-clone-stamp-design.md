# 克隆图章（设计）— 2026-10-17

## 0. 一句话

「点修」第二行加「克隆」：选一个源点，在目标处涂抹，把源点附近的内容复制过去。
第一笔落点与源点的差就是后续所有笔画的固定偏移。

## 1. 像素规则

- 源数据取**操作前的原图副本**，多笔不会互相复制已经复制过的内容；
- 每一笔先按软边笔刷盖出最大覆盖率掩码，再统一混合一次，避免线段重叠叠加；
- 源坐标 = 目标坐标 + 偏移；越界像素跳过；
- 克隆区外逐字节不变，alpha 按原图采样。
- 预览长边 ≤1400，提交按原尺寸；预览和提交共用 `cloneToBitmap`。

## 2. 交互

- 「点修 → 克隆」；
- 第二行：修补 / 选源点（选过变「换源点」）/ 笔刷 / 重来 / 取消 / 应用克隆；
- 选源点时画布进入取样态，点照片上的源点后回到涂抹层；
- 照片上显示「源」标记；偏移定下后，鼠标旁还有一个虚线源圈；
- 没选源点或没涂过时主按钮禁用。

## 3. 账本

应用后换当前这一版底图、记一笔账、可撤销；不推转盘格、不写对话、不动全局参数。
异步提交沿用 `baseEdit` 的过期作废检查；取消 / 切屏 / 换照片释放预览位图。

## 4. 验证

- `image/clone.test.ts`：复制方向、软边、多笔、空点列 / 半径 0 / 源点越界恒等；
- `App.tools.test.tsx`：选源点 → 偏移 → 预览 → 提交；
- 真浏览器：红色源点复制到蓝色区、未涂区不变、390px 第二行可用。
