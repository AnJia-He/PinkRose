# 实时相机拍摄 —— 2026-10-18

## 目标

在纯 Web 产品里接入真实拍摄相机：内置摄像头、USB/UVC 相机、采集卡等
浏览器能看见的设备，实时取景后按快门，把一帧直接送进现有修图链路。

单反厂商 SDK 的遥控 / 参数控制需要原生桥，不在纯 Web 范围；这里的边界
在 UI 和文档里写清楚。

## 能力

- `getUserMedia({ audio:false, video })`，优先 1920×1080。
- `enumerateDevices` 列出 videoinput；设备下拉切换，记住上次选择，`devicechange` 时刷新。
- 前 / 后切换、镜像、三分网格、0 / 3 / 5 秒倒计时、快门。
- 单张 / 3 / 5 张连拍：拍完在取景层里选一张，或整组送入批量处理；
  其余帧和预览 URL 一起释放。
- 相机 track 暴露 `torch` / `zoom` 时提供补光与变焦；不支持时自动隐藏。
- 关闭 / 卸载停止所有 track，避免相机指示灯常亮。

## 失败路径

- 非 HTTPS / localhost：提示换 HTTPS 或先用系统拍照。
- 权限拒绝 / 无设备 / 设备被占用：分别给出可执行的权限、接线、关闭占用提示。
- 取景未出画面：提示稍等或换相机，不把页面带走。

## 验收

- 单测：请求、快门 File、track 清理、错误提示。
- Chromium 假相机：预览 → 拍照 → 编辑器出现。
- WebKit：入口可开、失败有提示、390px 弹层不横向溢出。
