# 高光 / 阴影裁切警告设计 —— 2026-10-21

## 背景

直方图能给整体溢出比例，但不能告诉用户“具体哪一块已经纯白 / 纯黑”。
专业修图工具通常提供高光 / 暗部裁切警告。这个功能只用于查看，
不能改变照片、作品参数或导出字节。

## 交互

- 调色画布右下角缩放条新增「高光」「暗部」两个开关。
- 高光：任一通道达到 251–255 的区域显示红色覆盖。
- 暗部：三通道都在 0–4 的区域显示蓝色覆盖。
- 两个警告可以同时开启，关闭后立即恢复原画面。
- 裁切、局部、人像等模态工具打开时不显示；对比原图或按住看原图时也不覆盖。
- 警告状态是临时查看状态，不进入会话、作品或预设。

## 实现

- `TonePipeline.readClippingMask` 复用直方图的 128×128 离屏渲染，
  在主画布之外读回一份小图并生成 mask。
- `render/clipping.ts` 只产出 `0 / 1 / 2`（正常 / 高光 / 阴影）。
- Canvas 用独立 2D `<canvas class="canvas-clipping">` 叠在照片上，按当前照片盒缩放。
- 主 WebGL 画布和导出不受影响；浏览器验收会比较开启警告前后的
  `canvas.toDataURL()`，要求完全一致。

## 验证

- `src/render/clipping.test.ts`：任一通道高光、三通道阴影、正常像素、尺寸错误。
- `src/ui/Canvas.test.tsx`：两个开关、独立覆盖层、参数变化重算。
- `npm run check:clipping`：WebKit 桌面 + 390px；白区变红、黑区变蓝、
  关闭恢复、主画布导出字节不变、无溢出、控制台无错误。
