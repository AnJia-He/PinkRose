# 裁剪比例补全设计 —— 2026-10-18

## 目标

把裁剪比例从 1:1 / 4:3 / 3:4 / 16:9 补到常用社交和相机比例，并支持自定义
宽高比。比例只改变裁剪框，不放大原图，仍走原有「完成」账本。

## 比例

- 自由 / 1:1 / 4:5 / 3:4 / 9:16 / 16:9 / 3:2 / 2:3 / 4:3 / 原图。
- 自定义输入宽 : 高，范围 1 到 100 的数值输入；输入完成后点「应用比例」，
  避免每敲一个数字都按“只缩不放”收一次框。任一输入为 0 / 空时不更新比例。
- 选比例后裁剪框围绕原中心收进画面；角度变化仍按原有规则重置为最大内接矩形。

## 验收

- `CropControls.test.tsx`：4:5 / 9:16 / 3:2 和自定义 5:4 都调用正确的像素比；
  宽输入 0 不改变当前比例。
- 现有裁剪 App 测试继续通过。
- Chromium + WebKit：自定义 5:4 应用后输出 750×600（输入 800×600），
  390px 无横向溢出，无控制台错误。
