# 长图拼接 —— 2026-10-18

## 目标

补齐聊天记录、截图、步骤图常用的「长图拼接」：2–20 张照片按选择顺序，
纵向或横向接成一张长图。它不做重叠检测 / 透视融合，那是全景的职责。

## 几何

- 纵向固定宽度、横向固定高度，取 1080 / 1440 / 2048；按选定值缩放，
  原图较小会放大（不会凭空增加细节），长边上限才是硬保护。
- 每张按原比例缩放到固定边，帧与帧之间加间距。
- 圆角只裁每张图的外缘，背景填满整张画布。
- 总长超过 16384px（常见画布上限）时，整张图等比缩小，顺序不变。

## 输出

- JPG / PNG / WebP，质量 92%；PNG 忽略质量。
- 文件名 `第一张文件名_long.ext`。
- 预览按同一份 plan 缩到 720px 内，成片与预览不会两套排版。

## 验收

- 单测：纵向 / 横向尺寸、间距、长边上限、顺序、文件名、渲染 / 导出尺寸。
- 面板：少于 2 张不能生成；方向、格式、固定边进入引擎参数；上移改变第一张命名；下载后可重下。
- 390px + 桌面：入口、返回、选照片区、排版、预览占位、生成按钮都在视口内。
- Apple WebKit：作品页入口可打开，空工作区无控制台错误。
