# 局部模糊 / 马赛克（设计）— 2026-10-17

## 0. 一句话

「局部」工具新增两种效果：**模糊**和**马赛克**。仍用现有蒙版、画笔、强度和
「应用局部」账本链路，只改掩码覆盖到的像素。

## 1. 像素规则

- 模糊：可分离盒式模糊，半径随强度增长；先从操作前副本取色，再按
  `覆盖率 × 强度` 混回原像素。
- 马赛克：按画面绝对像素网格切块（强度越大块越大），块色取操作前平均色，
  再按 `覆盖率 × 强度` 混回。
- 掩码外逐字节不变；alpha 不动；强度 0 = 完全恒等。
- 只处理蒙版外接框和必要边距，不整图扫描。

## 2. 界面

局部第二行效果：调色 / 牙齿 / 亮眼 / 红眼 / **模糊 / 马赛克**。
选中后只显示「强度」；手机沿用横滑，不增加第二行高度。

## 3. 验证

- `image/localPrivacy.test.ts`：模糊降方差、马赛克块内同色、掩码外不变、强度 0 恒等。
- `App.tools.test.tsx`：模糊 / 马赛克走同一条局部提交。
- 真浏览器：涂抹区方差明显下降，未涂区不变，390px 按钮可达、无控制台错误。
