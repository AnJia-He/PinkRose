# 细节与质感：锐化 / 降噪 / 颗粒（设计）— 2026-10-17

## 0. 一句话

调色面板补上主流修图产品的「细节」组：**锐化、降噪、颗粒**。三根都是
0–100 的本地参数，0 = 完全不动；进面板、预设、会话、作品配方和对话路由，
但**不改任何老参数的顺序和含义**。

## 1. 为什么是这三项

2026-10-17 对 Lightroom、Snapseed、VSCO、醒图、美图秀秀的调整面板做了一遍
功能面盘点：老八根、自然饱和度、色彩平衡、分离色调、LUT、曲线、HSL 之外，
**细节 / Detail** 是出现频率最高、且不依赖新子系统的下一批：

- 锐化：让边缘更清楚，和已有的「清晰度」互补（清晰度管中频局部反差，
  锐化管高频轮廓）；
- 降噪：夜景、高感照片的刚需，必须保边，不能像高斯模糊那样把五官糊掉；
- 颗粒：胶片质感、街拍和复古方向最常用的收尾效果。

三项都能在**同一次 fragment shader** 里完成，不需要新纹理、不需要多 pass，
也不需要绑定任何人脸/语义模型。曲线和 HSL 需要新的拖点控件和更大的参数表，
留到后续批次。

## 2. 参数契约

- 字段：`sharpen` / `noiseReduction` / `grain`，范围 **[0, 100]**，中立点 0。
- `PARAM_KEYS` 和 `PARAM_GROUPS` 都**追加在末尾**：
  - 老组顺序：光效 / 色彩 / 色彩平衡 / 分离色调 / 效果；
  - 新组：**细节** = `[sharpen, noiseReduction, grain]`。
- `ZERO` / `clampAdjustments` / `toUnit` 逐字段写死，缺键老数据落 0。
- 总参数从 16 个变成 19 个；预设、作品详情、会话恢复都跟着 `PARAM_KEYS` 走。

## 3. 着色器

### 3.1 顺序

细节组和清晰度 / 磨皮同族，**都在色调链之前**，作用在原始纹理上：

```
清晰度 → 磨皮 → 降噪 → 锐化 → 色温 → 曝光 → 高光/阴影 → 对比度
→ 饱和度 → 自然饱和度 → 分离色调 → 暗角 → 颗粒 → LUT
```

颗粒放在暗角之后、LUT 之前：LUT 仍然保持「永远是最后一步」的既有契约。

### 3.2 降噪

8 邻域双边平均：邻域亮度差越大，权重越小。这样毛孔/噪点被平均掉，
眼睛、发丝这类高反差边保留。混合系数是 `uNoiseReduction * 0.8`，
强度 0 时整段跳过（uniform 分支），与没有这一步逐字节一致。

### 3.3 锐化

原始纹理的 4 邻域均值当低频，`base - sharpBlur` 当高频细节，
按 `uSharpen * 1.1` 加回 `c`。强度 0 时不做任何事；上限留一点克制，
避免把白边和噪点一起放大。

### 3.4 颗粒

用 `gl_FragCoord` 的确定性 hash 生成单色噪声，幅度是
`(n - 0.5) * uGrain * 0.12`。同一张照片每次渲染颗粒位置一致，
不会闪；强度 0 时加 0。

## 4. 界面与产品接线

- 面板自动多出「细节」组和三条滑杆，标签「锐化 / 降噪 / 颗粒」。
- 内置预设新增「街拍质感」（锐化 32、颗粒 18、轻提暗部），让功能在预设栏
  里看得见。
- 对话路由：说「边缘清楚一点」「噪点压一下」「加点胶片颗粒」时，模型给
  `sharpen` / `noiseReduction` / `grain` 正增量，走本地 `params`，不生成。
- 作品详情页的「这张图怎么来的」按 `PARAM_KEYS` 自动列出改过的项。
- 小程序本轮不做界面；共享参数 / 着色器镜像仍由同步脚本保持一致。
