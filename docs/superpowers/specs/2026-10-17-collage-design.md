# 多图拼图设计 —— 2026-10-17

## 目标

给 Web 修图产品补上多图拼图：从本地选 2–9 张照片，按统一版式、间距、圆角和
背景色拼成一张成品，并直接下载。全部在本机完成，不调用模型。

入口放在「作品」页头，和「批量处理」并列，不增加一级导航。

## 版式

- `自动`：3 / 5 张用「大图在左」，其余用网格。
- `网格`：按画幅和照片数自动选 1–3 列；最后一行不足时等宽铺满。
- `大图在左`：第一张占左侧约 62%，其余纵向排列在右侧。
- `大图在上`：第一张占上方约 62%，其余横向排列在下方。
- 画幅：`1:1` / `4:5` / `3:4` / `16:9`。
- 长边：2048 / 1080。

每格照片按 `cover` 裁切居中，不拉伸。间距同时用作外边距；圆角在输出尺度上
按像素计算，预览按比例缩放。

## 导出

- JPG / PNG / WebP，JPG / WebP 质量 60–100。
- 拼图没有单一原图，因此不写回 EXIF；这是多图合成的明确限制。
- 文件名：`PinkRose-collage-YYYYMMDD-HHmm.<ext>`。
- 处理中显示当前文件名与进度，可停止；停止后不生成半成品。

## 验收

- `image/collage.test.ts`：画幅尺寸、各版式格数、边界与不重叠、自动版式选择。
- `ui/CollagePanel.test.tsx`：至少两张才能生成；成功生成后下载。
- 真浏览器：桌面与 390px，预览与导出尺寸一致、各格无拉伸、无横向溢出。
