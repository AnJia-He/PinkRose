# AI 局部消除（设计）— 2026-10-18

## 0. 一句话

在「点修」里加一个可按涂抹范围工作的 **AI 消除**：用户涂住要去掉的人或物，
只把选区周围的一小块送去云端改图模型，回图只贴回涂过的区域，掩码外保持原图。

## 1. 为什么现在需要它

已有的「消除路人」是对话栏里的整图固定动作：模型自己判断谁是路人，用户不能指定
电线、垃圾桶、广告牌、桌角或某一个人。市面上的修图产品几乎都有“涂哪里、消哪里”
的局部消除。这个缺口不是再加一个预设能补的，必须有选区。

## 2. 用户流程

1. 调色 → 点修 → 第二行「AI 消除」。
2. 用画笔涂住目标；橡皮修掉多涂的地方。
3. 主按钮「AI 消除」。现场一直显示「会消耗生成额度」。
4. 成功：当前这一版底图换成消除后的图，记一笔账，可「上一步」撤销；不占版本转盘。
5. 失败 / 取消：现场和掩码保留，不换底图；失败时给一句能照着做的话。

## 3. 算法与边界

- **裁切**：取选区外接框，四周留 45% 长边、至少 24px；夹在原图内。
- **送模**：把裁切图按比例放进 1024×1024 方图，留白用同一张裁切图的低透明度
  拉伸版铺底；再把掩码画成半透明红标。提示词明确“删除红标里的对象”，并写
  `Do not preserve the person ...`，避免服务端的保留人物保底句反向干扰。
- **回贴**：模型回图按实际尺寸缩放回裁切框，只在羽化后的掩码里混合；alpha 保持
  原图。掩码外一个字节都不动。
- **费用闸门**：选区超过照片面积 60% 或 250 万像素就拦下，提示分几次消；没涂、
  正在生成、正在打开照片时都不发请求。
- **失败边界**：结果取决于模型；不承诺“完全看不出痕迹”。模型回图尺寸不一致时
  按实际像素缩放，不拉伸原图。

## 4. 接线

- `src/image/aiErase.ts`：裁切计划、红标方图、纯回贴、面积闸门。
- `src/app/useAiErase.ts`：现场（掩码 / 笔刷）、付费请求、过期作废、账本提交。
- `src/ui/AiEraseControls.tsx`：第二行控件与费用提示。
- `src/App.tsx` / `src/ui/ToolBar.tsx`：`aiErase` 子工具、画布掩码层、忙碌态。
