# 拼图模板设计 —— 2026-10-18

## 目标

给现有拼图加五套一键成品模板，让用户不用逐项调版式就能得到常见的
网格 / 杂志 / 胶片条 / 大图故事 / 九宫格效果。

## 模板

- 经典网格：1:1，网格，间距 12，圆角 12，白底。
- 杂志：4:5，大图在左，间距 6，直角，黑底。
- 胶片条：16:9，网格，间距 18，圆角 4，黑底。
- 大图故事：3:4，大图在上，间距 14，圆角 18，米白底。
- 九宫格：1:1，网格，间距 4，直角，白底。

模板只改版式 / 画幅 / 间距 / 圆角 / 背景，不覆盖导出格式、质量和长边。
套用后用户仍可继续微调；任意一项改过，模板高亮自动取消。

## 接线

- `src/image/collage.ts`：`COLLAGE_TEMPLATES` 与 `collageTemplate(id)`。
- `ui/CollagePanel`：版式区顶部一组模板胶囊，`onClick` 把 patch 合进 options。
- 预览和导出仍走原有 `renderCollageCanvas` / `exportCollage`。

## 验收

- `image/collage.test.ts`：五套模板、杂志 patch、只含版式字段。
- `ui/CollagePanel.test.tsx`：点杂志后导出参数带 4:5 / 大图在左 / 6 / 0 / 黑底。
- 真浏览器（Chromium + WebKit）：五颗模板、杂志 4:5、胶片条 16:9、390px 不溢出。
