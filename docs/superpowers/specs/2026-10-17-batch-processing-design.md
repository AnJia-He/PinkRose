# 批量处理设计 —— 2026-10-17

## 目标

给 Web 修图产品补上市面同类产品常见的批量能力：一次选多张本地照片，
套同一套调色，按统一的格式 / 质量 / 长边导出，最后只下载一个 ZIP。

这是现有「作品」页的扩展，不新增一级导航。窄屏左栏已经接近一行放满，
再塞一颗「批量」会把导航撑出横向滚动；作品页本来就有「多选」和导出的语境。

## 范围

- 一次最多 20 张，避免在浏览器里同时持有过多全尺寸位图。
- 调色来源：内置预设 + 「我的预设」。
- 导出：JPG / PNG / WebP，60–100 质量，原尺寸 / 长边 2048 / 1080。
- 逐张进度、当前文件名、成功 / 失败清单。
- 单张失败继续处理后面的照片；全部失败时明确说没有可下载结果。
- 可中途停止；已经处理完的照片仍可打包下载。

不在本轮：

- 批量 AI 生成或需要上传服务端的重计算。
- 每张照片单独手调。
- ZIP 压缩（JPEG / WebP 本身已压缩；ZIP 用 store 方式，避免重复压缩耗时）。

## 实现

### 渲染与导出

复用现有 `TonePipeline`、`decodeImageFile`、`resizeBitmap`、
`buildExportBlob`、`exportSize`、`buildFilename`：

1. 解码为 sRGB 位图。
2. 按导出长边先缩图，减少 WebGL 纹理和内存峰值。
3. 管线渲染整套 `Adjustments`。
4. 写回原图 EXIF（JPG），再编码为 Blob。
5. 文件名不足时追加 `_2`、`_3`，防同名覆盖。

### ZIP

新增纯 TypeScript 的 store-only ZIP 写入器（本地文件头、中央目录、EOCD），
文件名使用 UTF-8 标志。不新增依赖，不修改锁文件。

### 界面

- 作品页头增加「批量处理」。
- 点开后在同一页内切换为批量工作区，左上「← 作品」返回。
- 选照片区支持点选和拖放；已选照片用一行一个的紧凑列表，可移除。
- 预设用原生 `<select>`，内置和「我的预设」分组。
- 导出设置复用 `ExportSettings`。
- 主按钮在未选照片 / 处理中 / 没有预设时禁用；处理中提供「停止」。
- 进度用原生 `<progress>` + 可读的「已完成 / 总数」文本。
- 失败项逐条列出文件名和原因，下载按钮只针对成功项。
