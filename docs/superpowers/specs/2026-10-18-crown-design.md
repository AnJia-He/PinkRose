# 人像颅顶 —— 2026-10-18

## 目标

补齐市面美颜常见的「高颅顶」。只用本地正脸框做几何变形，不引入关键点模型。

## 算法

- 颅顶带：从脸上方 0.38×脸高到脸下方 0.12×脸高，水平范围约 ±0.62×脸宽。
- 输出像素向下取样（`srcY += 0.20×脸高×强度×垂直×水平`），带内内容整体上移，
  视觉上额头和颅顶变高。
- 垂直 / 水平都用 smoothstep 淡出，避免头顶、额头和背景之间出现硬接缝。
- 脸下方、脸外逐字节不动；强度 0 恒等。

## 验收

- 单测：白带从额头下方被拉到上方，脸下方和脸外不变。
- App：拖动「颅顶」后预览与提交都带 `crown`，全局参数保持 ZERO。
- 390px / iPad / WebKit：人像行仍可横滑，主按钮和取消够得着。
