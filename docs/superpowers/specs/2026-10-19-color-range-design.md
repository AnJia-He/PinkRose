# 色彩范围选蒙版设计 —— 2026-10-19

## 1. 解决什么

「局部」原来只有涂抹 / 线性 / 径向三种蒙版。选天空、肤色、一件衣服这类
**颜色相近但形状不规则**的区域，手工涂很费事。这一轮补上主流修图产品的
Color Range：点一下画面上的颜色，按相近程度选出一整片。

## 2. 判据

纯函数在 `src/core/colorRange.ts`：

- 目标色和每个像素都转成 **HSV**；
- 距离 = 色相差（权重 × `min(s, sTarget)`） + 饱和度差 + 明度差；
- 灰度像素没有有意义的色相，权重自然趋 0，只按饱和度 / 明度比；
- `容差 0–100` 映射到最大距离 `0.025 + t × 0.5`；
- `羽化 0–100` 在阈值内侧留一段线性过渡，得到软边；
- alpha < 8 的像素不选。

HSV 而不是 RGB 距离：同一个红「亮一点 / 暗一点」在 RGB 里会被判得很远，
HSV 拆开明度后，亮部和暗部不会被一刀切掉。

## 3. 画布与性能

`src/image/colorRange.ts`：

1. 把底图缩到最长边 **1280**，读一份 RGBA 缓存；
2. 在缓存上取点击位置一小块的平均色（抗噪点）；
3. 算小蒙版，再用双线性放大回当前底图尺寸。

滑杆连续改时复用缓存，只重算小蒙版 —— 不用每拖一下重读一张 12 MP 原图。
蒙版本身是软边，放大后的轻微插值不影响观感。

## 4. 交互

- 「局部 → 色彩范围」显示「点选颜色」；
- 点一下按钮，画布进入取色态（顶部提示「点一下要选的颜色」）；
- 点画面后显示颜色小圆点、把蒙版以只读红色预览画出来；
- 「容差 / 羽化」滑杆实时重算；
- 「反选」对色彩范围也有效：选中的变成"和这个颜色不相近"的部分；
- 「扩边」-50~50 像素：正数外扩、负数内收，用来补掉颜色选区里的小洞 / 收紧边缘；
- 「应用局部」照旧烘焙；「存为层」会把 `color` 参数一起存进局部层；
- 刷新后点「局部层 1」会回到色彩范围模式，容差 / 羽化 / 反选 / 扩边都还在。

只读蒙版预览用 `RetouchOverlay` 的 `readOnly`：`pointer-events: none`，
点击穿到画布上取色，不会误涂。

## 5. 边界

- 色彩范围层的面积上限放宽到 **4,000,000 像素**（整片天空也能选），
  仍然保留「太大就拦」；慢的那一档会先画暗罩。
- 取色参数进会话 schema，服务端按 0–255 / 0–100 归一化。
- 蒙版仍按最长边 1280 存 PNG，受局部层 8 条 / 6,000,000 字符的总量限制。
