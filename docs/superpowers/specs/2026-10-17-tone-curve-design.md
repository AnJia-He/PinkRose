# 影调曲线（设计）— 2026-10-17

## 0. 一句话

调色面板补上主流修图软件都有的**曲线**：五个控制点（黑场 / 阴影 / 中间调 /
高光 / 白场），横轴原亮度、纵轴调整后亮度，用可拖点的曲线编辑器调，不是
五根普通滑杆。全部本地计算，0 = 五点落在对角线上、画面完全不变。

## 1. 为什么是五控制点

完整曲线编辑器允许任意加点，但参数会从"数字 record"变成点数组，牵动
会话 / 预设 / 作品 / 小程序共享层的持久化契约。这一批先做**固定五控制点**
的影调曲线：

- 黑场、白场、阴影、中间调、高光已经覆盖 90% 的日常曲线动作；
- 五个值仍是数字，能沿用 `Adjustments`、`PARAM_KEYS`、`clampAdjustments`、
  `toUnit` 和会话恢复；
- 拖点 UI 与完整曲线同形，后面要扩成任意加点时不用推翻面板语言。

## 2. 参数契约

五个参数追加在 HSL 之后，总参数从 43 个变成 **48 个**：

```
curveBlack / curveShadows / curveMidtones / curveHighlights / curveWhite
```

- 范围都是 [-100, 100]，中立点 0；
- 黑场只允许**向上抬**（负值无意义，夹回 0）；
- 白场只允许**向下压**（正值无意义，夹回 0）；
- 中间三点可正可负；
- 控制点算完后再做一次单调夹取，避免用户把阴影拖到中间调上面时曲线翻折。

CPU 唯一实现是 `src/core/toneCurve.ts`；着色器里 `curveAt()` 是同一组
常数和同一套单调夹取。

## 3. 着色器

位置：HSL 之后、分离色调之前。

1. 取当前像素亮度 `l = dot(c, LUMA)`，夹到 0~1；
2. 五段 smoothstep 插值得到 `curveAt(l)`；
3. 把差值 `curveAt(l) - l` 加到 RGB 三通道 —— 这样色相和饱和度关系不被
   曲线直接改写，只是整体明暗被抬高/压低；
4. `uCurveOn == 0` 时整段跳过，与没有曲线逐字节一致。

## 4. 界面

- 新增 `ui/ToneCurve`：SVG 网格 + 对角线参考线 + 曲线 + 五个可拖圆点；
- 控制点纵向拖动，键盘方向键一次 2、Shift + 方向键一次 10；
- 每个点 `role="slider"`，`aria-valuemin/max/now` 报真实参数；
- 下方一行五个读数（黑场 / 阴影 / 中间调 / 高光 / 白场）；
- 「拉直」把五个点归零，不影响别的调色参数；
- 组图标用 `Spline`（一条曲线），和 HSL 的彩虹、细节的放大镜分开。

## 5. 不做什么

- 不做任意加点 / 多通道 RGB 曲线 / 曲线预设库 —— 先把五控制点做稳；
- 不把曲线塞进对话路由：模型对"曲线形状"没有稳定标尺，交给手动面板；
- 不动小程序界面；共享参数与着色器镜像仍由同步脚本保持一致。
