# 几何透视校正（设计）— 2026-10-17

## 0. 一句话

调色面板补上「几何」组：垂直透视 / 水平透视两根滑块，实时把梯形楼体、
歪掉的墙面拉正。它改的是采样网格，不裁底图、不推快照，可随参数保存和还原。

## 1. 为什么放在渲染参数里

透视有两种做法：

1. **烘焙进底图**：像裁剪一样产出一张新图；
2. **非破坏的采样变换**：把透视量存进 `Adjustments`，每次渲染时改变
   “输出像素去原始纹理哪里取样”。

第 2 种更符合调色面板现有的可逆模型：拖错了直接回 0，不需要撤销一整刀；
也能随会话 / 作品 / 预设计保存。代价是它只做全局梯形校正，不做四角自由
拖拽或局部塑形。四角自由透视另走 **裁剪里的烘焙子模式**，见 §4.5。

## 2. 参数

```ts
perspectiveV: number  // -100~100，垂直梯形
perspectiveH: number  // -100~100，水平梯形
```

- 0 = 完全恒等；
- 正 V 校正“上窄下宽”（源图上窄下宽的楼体）；
- 负 V 校正“上宽下窄”；
- 负 H 校正“左窄右宽”，正 H 校正“右窄左宽”；
- 两根可以同时用。

## 3. 采样变换

在 fragment shader 最开头，把 `vUv` 变成 `perspectiveUv(vUv)`：

```
q = (p - 0.5) * zoom
src = q / (1 + V*q.y + H*q.x)
```

这是一条真正的投影变换（不是简单的双线性拉伸），所以直线仍然是直线。
为了避免四角露出空白，先按四个输出角算出映射后的最大坐标，再迭代求一个
统一的 zoom，把所有角压回 `[0,1]` 内。`uv` 进入色调链之前会 clamp；
暗角仍用 `vUv`（输出坐标），不会跟着透视被拉歪。

## 4. 界面与模型

- 调色面板新增「几何」组，两根本地滑块，范围 -100~100；
- 面板组图标用 `Scan`；
- 路由器新增 `perspectiveV` / `perspectiveH`，遇到“把楼拍正”这类话走
  params，不走生成；
- 作品详情页 / 预设 / 会话落盘沿用现有参数管线，不需要新 schema。

## 5. 不做什么

- 不做镜头畸变 / 鱼眼校正；
- 不做人脸塑形（下一轮独立做）；
- 不动小程序界面。

## 4.5 四角自由透视（烘焙子模式）

「裁剪」第二行新增「透视」：照片上四个角各一个把手，用户拖到画面里矩形
物体的四个角，再点「应用透视」。

- 纯算式在 `core/perspective.ts`：单位正方形 → 四边形投影矩阵；
- 像素落点在 `image/perspective.ts`：逐输出像素反投影 + 双线性采样；
- 输出尺寸取四角外接框，四角分别映射到输出四角；
- 应用后产出新底图，走 `baseEdit` 记一笔；不推快照、不进转盘、不动参数；
- 保留 alpha，抠过图的照片也能继续做透视；
- 工具行不新增格子：「透视」和「裁剪」共用第一颗，点亮状态跟着「裁剪」。
