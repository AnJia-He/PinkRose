# 肤色美颜：美白 / 红润（设计）— 2026-10-17

## 0. 一句话

在已有磨皮旁边补两项肤色美颜：**美白**和**红润**。都只作用在 Cb/Cr
肤色蒙版里，背景、衣服、头发不跟着变；0 = 完全不动。

## 1. 参数

- `skinBrighten`：0~100，肤色提亮，最多约 +35% 亮度；
- `skinRosy`：0~100，肤色加一点暖红气色，最多加 `(0.10, 0.02, -0.04)`。
- 追加在 48 个参数之后，总参数 **50**；美颜组两项。

## 2. 着色器

把原来磨皮块里私有的肤色蒙版提成 **共享的 `skin`**：

1. 在原始 `base` 上算 Cb/Cr 软蒙版（保留原来的保守区间）；
2. 磨皮块继续用这个 `skin`；
3. 曲线之后、分离色调之前应用美颜：
   - `beautified = c * (1 + skinBrighten * 0.35)`
   - `beautified += vec3(0.10, 0.02, -0.04) * skinRosy`
   - `c = mix(c, beautified, skin)`
4. 两项全 0 时整段跳过；肤色权重 0 的像素一个字节不变。

## 3. 产品接线

- 调色面板新增「美颜」组（美白 / 红润），图标笑脸。
- 「柔光人像」预设补 `skinBrighten: 15, skinRosy: 8`。
- 对话路由新增两项：说「脸白一点 / 气色好一点 / 红润一点」走 params，
  不走生成。
- 作品详情、会话、我的预设都跟 `PARAM_KEYS` 自动走。

## 4. 验证

- 50 键 / 52 uniform / 14 个提示词参数。
- 着色器真机编译。
- 合成肤色图探针：美白/红润只改肤色块，灰色背景不变。
