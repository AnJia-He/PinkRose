# 九宫格切图 —— 2026-10-18

## 目标

补齐社交发布前常见的「九宫格 / 网格切图」：一张照片切成 N×N 张独立图片，
按顺序打包下载，发出去后按序号拼回原图。全程本地画布计算，不调用模型。

## 几何

- 网格：2×2 / 3×3 / 4×4，行优先编号 1 → N²。
- 单格尺寸按原图格子计算，再缩到单格长边上限（1080 / 2048）以内；
  **只缩不放**，小图保持原尺寸。
- 间距夹在 `min(tileW, tileH) - 2` 以内，避免极端值把内容吃光。
- 间距以内按 cover 居中裁切，格子比例和原格略有差异时只裁边缘、不拉伸。

## 输出

- 圆角在每张图的外缘裁切；背景可为白色或 PNG / WebP 透明底。
- JPG / PNG，质量 92%；PNG 忽略质量。
- 每张命名 `原文件名_序号.ext`，外层 ZIP 命名 `原文件名_grid.zip`。
- ZIP 复用 `src/batch/zip.ts` 的 store-only 写入器，零新依赖。

## 验收

- 单测：9 格覆盖整图、无重叠、单格不放大、间距夹取、ZIP 条目数 = N²。
- 面板：未选照片不能下载；切法 / 格式 / 透明底进入引擎参数；下载后可直接重下。
- 390px + 桌面布局：返回、选照片区、切法、预览占位、下载按钮都在视口内，不横向溢出。
- Apple WebKit：作品页入口可打开，空工作区无控制台错误。
