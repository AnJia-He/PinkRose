# HSL 定向取色（设计）— 2026-10-19

## 0. 一句话

HSL 组新增「从照片取色」：点一下画面上的颜色，自动切到最近的色带，
再拖色相 / 饱和度 / 明度。只改参数，不生成、不花钱。

## 1. 规则

- RGB → HSV；饱和度低于 0.12 或明度低于 0.08 时返回 null，
  明确提示「换一块有颜色的地方」，不硬猜色带。
- 色相按环形距离匹配八条色带；红色跨 0 / 1 边界也按同一个距离算。
- 取色只改面板当前选中哪条色带，三根滑块仍写真实的
  `hslRedHue` / `hslRedSat` / ... 参数。
- 同一色带连续取色也要重新生效（用递增序号，而不是只比较色带 id）。

## 2. 界面

- HSL 组底部一颗「从照片取色」，点一次进入取样，再点一下照片完成。
- 取样期间画布显示提示「点一下画面里要调的颜色」；完成或点灰后退出取样。
- 打开别的工具、切到别的屏或重置临时状态时，取样模式一起收掉。

## 3. 验证

- `core/hslPick.test.ts`：纯色映射、红 / 洋红边界、灰 / 暗色返回 null。
- `AdjustmentPanel.behavior.test.tsx`：按钮把动作交给上层；取回蓝色后
  面板切到蓝带。
- `App.adjust.test.tsx`：画布取样 → 面板切色带、不调用生成；
  点到灰色时提示换一块颜色且不切色带。
- 真浏览器 390px：按钮可达、无横向溢出、控制台无错误。
