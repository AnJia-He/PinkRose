# HSL 分色（设计）— 2026-10-17

## 0. 一句话

调色面板补上主流修图软件都有的 **HSL 分色**：红 / 橙 / 黄 / 绿 / 青 / 蓝 /
紫 / 洋红八条色带，每条各有**色相 / 饱和度 / 明度**三根轴。全部本地计算，
0 = 完全不动，进预设、会话、作品配方和作品详情。

## 1. 为什么是 HSL

2026-10-04 的专业面板盘点里，曲线、HSL、局部调整是排在 LUT 之后的下一批。
2026-10-17 已经补了「细节」组；HSL 是下一个**不需要新控件子系统、但用户
一眼认得出来**的专业能力：

- 只调天空的蓝、只调肤色里的橙、只压草地里的绿，是旅拍和电商修图的日常；
- 现有「饱和度」是整张图一起动，做不到"只改一种颜色"；
- 它只有数字参数，不需要新的纹理或多 pass，适合沿用现有管线。

曲线需要新的拖点编辑器和曲线纹理，留到下一批。

## 2. 参数契约

八条色带 × 三轴 = 24 个参数，追加在老参数之后：

```
hslRedHue / hslRedSat / hslRedLum
...
hslMagentaHue / hslMagentaSat / hslMagentaLum
```

- 范围都是 **[-100, 100]**，中立点 0。
- `HSL_BANDS` 是色带的唯一清单（id / 显示名 / 色相中心 / 三个键）；
  `HSL_KEYS` 是 24 个键的扁平顺序，`PARAM_KEYS` 末尾直接展开它。
- 面板只同时显示选中色带的三根滑块；`PARAM_GROUPS` 的 `hsl` 组仍然列出
  全部 24 个键，保证顺序、配方、落盘一致。
- 总参数从 19 个变成 **43 个**；老 19 个的顺序和含义一个不动。

## 3. 着色器

位置：饱和度 / 自然饱和度之后，分离色调之前。

1. 用标准 RGB→HSV 转换拿到色相、饱和度、明度；
2. 对八条色带算一个软权重（色相环距离 + `smoothstep`），按权重累加三轴；
3. 权重和归一化，避免落在两条色带中间的颜色被加倍；
4. 色相最多偏移 ±60°，饱和度最多 ±0.5，明度最多 ±0.35；
5. `uHslOn == 0` 时整段跳过，与没有 HSL 逐字节一致。

色相、饱和度、明度的方向约定：

- 色相：负值往色相环逆时针，正值顺时针；
- 饱和度：负值更灰，正值更艳；
- 明度：负值更暗，正值更亮。

## 4. 界面

- 新增 `ui/HslControls`：上方八个色带按钮（四列两行），下方三根
  `色相 / 饱和度 / 明度` 滑块。
- 色点使用**内容色**（和色轮、渐变轨同类例外），其余颜色走主题令牌。
- 选中色带用 `aria-pressed` 报状态；色带按钮有 `aria-label`（「红色」等）。
- 组图标用彩虹（`Rainbow`），和「细节」的放大镜分开。

## 5. 不做什么

- **不把 HSL 塞进对话路由**：24 条对模型的标尺太细，容易乱设；用户说
  "让红色艳一点"时现有饱和度/自然饱和度已经能覆盖大部分意图。
- **不动小程序界面**：共享参数与着色器镜像由同步脚本保持一致，小程序
  没有 HSL 面板是已知边界。
- **不做曲线**：它需要独立的拖点编辑器 + 曲线纹理，另开一批。
