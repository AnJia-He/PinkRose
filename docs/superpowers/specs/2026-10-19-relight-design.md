# 方向光 / 打光设计 —— 2026-10-19

## 0. 背景

市场常见的「打光 / 光影重塑」是在现有照片上重新决定主光方向，让平光变立体、
逆光更有氛围；它不是换背景，也不应该重画五官。现有「装饰 → 光效」只有逆光、
漏光、光斑、霓虹四种装饰性光效，缺一个真正可调方向的打光。

## 1. 交互

- 「装饰 → 光效」新增第五个预设「方向光」；
- 选中后出现「光源方向」0~360° 和「冷暖」-100~100 两根滑杆；
- 方向口径：0° 上方、90° 右侧、180° 下方、270° 左侧；默认 315°（左上）；
- 强度仍是原来的 0~100，0 = 一个字节都不动；
- 预览走 `LightOverlay`，成片走 `lightToBitmap`，两边共用 `drawLight`。

## 2. 算法

- 用光源方向单位向量在画面一侧放一个径向「热区」，用 `soft-light` 提亮；
- 对侧放一个更低强度的暗部渐变，用 `multiply` 压暗，形成体积感；
- 冷暖只改高光染色（冷蓝 ↔ 暖橙），不整体改白平衡；
- 仍然只做 2D 合成，不改变构图、五官和纹理。

## 3. 验证

- `image/light.test.ts`：五种预设；方向 0/90 的渐变中心不同；强度 0 不画；
- `App.tools.test.tsx`：方向光控件出现，角度 / 冷暖进入 `lightToBitmap`；
- 真 Chromium：角度 360、冷暖 100 应用后画布像素和变化 17,261,710，
  说明预览设置确实进入成片；登录后控制台无错误；
- iPhone WebKit 390×844：第二行高度 48.5px、页面无横向溢出、应用按钮可达。
