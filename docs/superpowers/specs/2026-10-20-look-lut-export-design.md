# 当前外观导出 LUT 设计 —— 2026-10-20

## 目标

让用户把调色面板里做出来的颜色带走：导出标准 33³ `.cube`，可以再导入本产品，
也可以给支持 LUT 的剪辑 / 调色软件使用。全程本地 WebGL，不上传照片。

## 能烘焙什么

3D LUT 只表达“输入颜色 → 输出颜色”，因此只烘焙逐像素颜色参数：

- 光效（曝光 / 对比 / 高光 / 阴影 / 黑白场）
- 色彩（色温 / 自然饱和度 / 饱和度 / 色彩平衡 / 分离色调）
- HSL、整体曲线、RGB 曲线
- 当前正在用的 Lut 及其强度

清晰度、暗角、纹理、锐化、降噪、颗粒、去雾、HDR、柔光、美颜、局部蒙版、
镜头校正 / 虚化、透视都不进 LUT；它们依赖邻域、坐标、蒙版或人脸。

## 实现

1. 生成 33 个蓝色切片的横向色卡图集（一列一块，块内 x = r、y = g）。
2. 交给现有 `TonePipeline` / 同一个 shader 渲染，颜色顺序和画面完全同源。
3. `readPixels` 读回，翻成自上而下，按标准 `.cube` 顺序（红最快、蓝最慢）
   写出 35,937 条记录。
4. 输出固定 `DOMAIN_MIN 0 0 0` / `DOMAIN_MAX 1 1 1`；TITLE 做引号 / 换行清理。

## UI

调色面板「Lut」一栏底部：

- 第一颗「生成 .cube」异步生成；
- 生成成功后出现「下载 .cube」和「重新生成」；
- 分两步是为了让下载发生在新鲜用户手势里，避免 Safari 拦截；
- 参数或当前 Lut 一变，旧文件自动失效，避免下载到上一次的外观。

## 验证

- `export/lutExport.test.ts`：空间效果归零、`.cube` 头与红最快顺序。
- `ui/LutExporter.test.tsx`：生成 → 下载、参数变化失效、失败提示。
- `npm run check:lut-export`：WebKit 真浏览器生成并下载；恒等灰色 = 0.502，
  色温 100 后同一灰色 = 0.600 / 0.502 / 0.400；390px 不溢出、控制台无错。

## 不做

- 不把空间 / 局部效果硬塞进 LUT。
- 不做 65³（文件约 4 倍，33³ 已覆盖常见交付）。
- 不自动上传到服务端；下载就是本地 Blob。
