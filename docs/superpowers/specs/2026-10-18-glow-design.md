# 柔光 / 光晕（设计）— 2026-10-18

## 0. 一句话

调色面板「效果」组新增 **柔光**：让高光向周围轻轻溢出，形成柔和光晕。
适合逆光人像、夜景灯牌、梦幻氛围；0 = 不动，全程本地 fragment shader。

## 1. 参数与着色器

- `glow` 0~100，中立点 0；效果组第六根；
- 在 HDR 之后、色温之前：
  - 取 2px / 4px 两圈共 8 个邻域采样；
  - 只对**亮部**做 screen blend：`max(halo - 0.45, 0) * glow * gate * 0.9`；
  - `gate = smoothstep(0.45, 0.90, halo 亮度)`，中灰墙不发光；
  - `uGlow == 0` 整段跳过，老照片逐字节不变；
- 总参数 75，uniform 78。
