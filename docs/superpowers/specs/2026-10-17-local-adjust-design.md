# 局部调整画笔（设计）— 2026-10-17

## 0. 一句话

工具行补上「局部」：先用自由涂抹或线性/径向渐变圈出一块，再只对这块调
**亮度 / 对比度 / 饱和度 / 色温**，按「应用局部」把结果写进当前这一版的底图。它不改全局
参数、不进转盘、不写对话，账本记一笔，随时能撤销。

## 1. 这一版为什么是烘焙的

主流修图产品的局部调整有两种形态：

1. **可回编辑的蒙版层**：蒙版和局部参数进会话 / 作品 schema，之后还能改；
2. **烘焙的局部操作**：像 Snapseed 的局部，应用后写进当前底图。

第 1 种要新增蒙版纹理、局部层数据模型、会话迁移和渲染多 pass，是一整个
子系统；第 2 种能完全复用现有的 `app/baseEdit.ts` 骨架和账本：

- 掩码复用 `core/retouch` + `ui/RetouchOverlay`；
- 提交复用裁剪 / 点修 / 磨皮的「新底图 + 记一笔 + 可撤销」三条；
- 不碰 `Adjustments`（48 个全局参数）和会话 schema；
- 用户马上能得到"只提亮脸 / 只压暗天空 / 只给草地加饱和"的效果。

因此这一版明确叫**局部调整**，不冒充可回编辑的蒙版层；后续再做图层。

## 2. 参数

局部状态只在这次工具现场里存在，不写进全局参数：

```
radius / mode / maskKind / gradient / effect / exposure / contrast / saturation /
temperature / effectStrength
```

- `maskKind` 是 `brush` / `linear` / `radial`；后两者共用一份归一化
  `gradient { start, end, feather }`，坐标相对照片，缩放/平移不影响；
- 线性渐变：起点之前全生效、终点之后归零，中间 smoothstep；径向渐变：
  起点是圆心、终点到圆心的距离是外半径，`feather` 控制过渡比例；
- 四个调色值都是 **-100 ~ 100**，0 = 不动；
- `effect` 有 `tone` / `teeth` / `eyes` / `redeye` 四种：调色走四项数值，另外三种走
  `effectStrength`（0 ~ 100，默认 60）的固定预设；
- 牙齿预设压黄、轻微提亮；亮眼预设提亮并拉开明暗，二者都只作用于画笔涂选区；
- 红眼预设只降低明显偏红像素的红通道（红比蓝/绿高 15% 起、40% 以上全开），
  眼白、肤色和其它通道尽量不动；
- 主按钮「应用局部」只在「涂过 + 当前模式有实际效果 + 没在算」时可用；
- 应用后这些值不保留，要重调就撤销这一笔再画。

牙齿 / 亮眼 / 红眼是**手动涂选美颜**，不做人脸或五官关键点识别；文案不能暗示
已经自动找到牙齿、眼睛或红眼。

## 3. 像素引擎

`src/image/localAdjust.ts`：

1. `maskBounds` 找掩码外接框，只算这一块；
2. 对框内每个像素取 `coverage/255`；
3. 用**同一份** `core/tone.ts` 的 `applyTone` 算局部色调（曝光在线性空间、
   对比度绕中灰、饱和度朝灰点、色温抬红压蓝）；
   牙齿 / 亮眼把选中模式的固定参数交给同一个 `applyTone`；红眼只做条件式红通道压制；
4. 渐变蒙版在提交前由纯函数写入同一张覆盖率缓冲；拖动时只更新预览，
   不在每一帧重算整张蒙版；
5. 按 coverage 混合回原像素；coverage 0 的像素一个字节都不写；
6. 产出新底图，交给 `app/baseEdit.ts` 记账。

面积上限和点修/磨皮同一档：外接框 > 120 万像素拦下，提示分几次调；
> 15 万像素才盖「正在算」的暗罩，小笔刷不闪。

## 4. 界面

- 工具行第五颗「局部」，图标 `Brush`（和点修的橡皮分开）；
- 第二行：调色 / 牙齿 / 亮眼 / 红眼、涂抹 / 线性 / 径向、画笔/橡皮、笔刷或羽化、
  当前模式的滑杆、取消、应用局部；
- 调色模式显示亮度 / 对比度 / 饱和度 / 色温；牙齿 / 亮眼 / 红眼只显示强度；
- 线性 / 径向时照片上出现可拖的渐变预览：线性拖方向，径向从圆心拖半径；
- 窄屏工具行收紧内边距，五颗仍在 390px 内；第二行走既有的横向滚动，
  「取消 / 应用局部」用 sticky 钉在右边；
- 应用后工具收掉，画面换成本地调整后的底图；全局调色面板的同名滑杆不动。

## 5. 不做什么

- 不做可回编辑的蒙版图层（下一轮：蒙版 + 局部参数进 schema、多 pass 渲染）；
- 不做局部清晰度 / 磨皮（已有的磨皮画笔是独立工具）；
- 不动小程序。
