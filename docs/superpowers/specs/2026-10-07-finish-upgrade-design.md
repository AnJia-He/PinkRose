# 全站「完成度升级」设计文档（2026-10-07）

> 一句话：**什么都不换，只把已有的做讲究。** 节奏、字号、细节三把尺子立起来，
> 全站（工具 + 门面）照同一套走。不碰结构、不碰布局、不碰文案、不碰颜色主体系。

## 0. 来路（为什么有这一轮）

用户发来一张别处做的后台界面截图（视频标题：「让页面看起来更加克制」），
问「为什么人家用 skill 做的这么好看，要不重新设计一下我们的前端」。拆解之后：

- 那张图的好看 = **九成表层纪律**（几乎无彩、发丝线分层、小灰标签压大字值、
  数字对齐、间距同一把尺子），不是特殊布局；
- 我们自己已经是同一族（10-06 治掉「朦胧、脏」之后尤其明显），
  真差的是**排版的尺子**和一批**几十处的小不齐**；
- 那类演示页是**一屏静态样张**，我们是一套带三十多种状态的真工具 ——
  所以结论是「不推倒重来，做一次完成度升级」。

用户在画板（visual companion）上逐屏确认了三轮（见 §5 证据指针），
选了 **A · 表层精修**（不做 B · 重点屏重排；B 记在「不做清单」，随时可加码）。

## 1. 节奏尺子（已定：B · 克制 · 呼吸）

**规矩**：同一类"关系"，全站同一个值；不同类的关系，值有梯度。
"松一档"不是处处放大，是**把混着的值收成一把**：

| 关系 | 定值 | 出现在哪（改动示例） |
|---|---|---|
| 滑块行距（工具面板） | **36px**（30→36） | 调色面板 15 根滑块 |
| 组与组之间 | **24 / 16**（16/12→24/16） | 调色面板的五组 |
| 面板内边距 | **28**（24→28） | 调色面板四周 |
| 工具行/芯片 | padding **10/14**、芯片 **6/14** | 裁剪/点修/对比那一行 |
| 预设栏四周 | **16 / 12 / 20**；格子缝 **16 / 10** | 照片左边那排 |
| 对话块与块 | **16**（12→16） | 气泡之间 |
| 气泡内边距 | **11 / 15**（9/13→11/15） | 用户/助手气泡 |
| 输入行 | **14 / 18**（12/16→14/18） | 说话改图的输入框那一行 |
| 列表行与行 | **12**（8→12） | 会话列表 |
| 列表行内边距 | **10 / 14**（8/12→10/14） | 会话行 |
| 日期分组与分组 | **32**（24→32） | 会话列表、作品页 |
| 作品网格缝 | **16**（12→16） | 作品页格子 |
| 门面：标题→内容 | **72**（64/76→72） | 产品区 / 对比区 / bento 区统一 |
| 门面：卡片内边距 | **50**（46→50） | bento 格子 |

⚠️ 窄屏（≤640）跟同一把尺子；个别处按窄屏那一档另给（面板在窄屏左右收到 20），
以 `check:layout` 的数字为准（那边有照片尺寸的硬判据，改动会动到它）。

## 2. 字号尺子（app 九档 + 门面五档）

**合并账（四档"半档"消失）**：
- `12.5 → 12`（约 12 处：卡片提示、会话问答、菜单项、图例、末尾句、用量小标签…）
- `13.5 → 14`（对话气泡）
- `14.5 → 14`（欢迎页输入框）
- `18 → 17`（详情页改名输入框）

**字重**：app 只留 **400 / 600**（现状：`.gallery-day-title` 是 500，唯一的杂音，→400）。
**数字**：一切会变化/成列的数字走**等宽**（`tabular-nums`）—— 已有大半，补上
会话列表「N 步」这类。
⚠️ **门面例外**：门面保持自己的 380（正文）/ 500（按钮、卡片小标题）/ 600（标题）
—— 它是营销页、有自己的语域（这一条是**故意的**，不许被"统一"顺手抹掉；
但也不许再出现第四种字重）。

### 2.2 门面：两个半档归位

## 6. 实施顺序（给 plan 用）

1. **批 1 · 字阶 + 微修**（纯 CSS + 4 处 tsx strokeWidth）：合并四档半档、
   字重、等宽、门面字号、门面圆角、图标线宽。跑 `npm test` + `typecheck`
   （没有测试量字号，这一批靠真机截图与基准对）。
2. **批 2 · 节奏尺子（工具四屏）**：调色面板 / 对话 / 作品页 / 会话列表。
   跑 `check:layout`（间距改动会动到它量的数字，阈值有富余但要亲眼过）。
3. **批 3 · 剩余屏吃同一把尺子**：设置三页、详情页、空态、窄屏各档复验。
4. **批 4 · 门面七处 + 深色复验**（浅深两种模式各拍一遍）。

每批结束：`npm test` + `npm run typecheck` 两个都绿 + 真机截图对照 §5 基准。
（`check:layout` 在批 2/3 必跑；动了 `src/render/` 才需要 `check:lut`，本轮不碰。）
