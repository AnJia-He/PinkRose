# 滤镜（LUT）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用户能从设置里导入 `.cube` 滤镜，并在微调区（点缩略图）和对话区（说话 + 按钮）两处使用它；滤镜排在调色管线最后，和原图按强度混合。

**Architecture:** 解析器在 `shared/`（前后端共用，服务端为准）；服务端新表 `luts` + 五个接口，文件走既有的 `storage.ts`（新根目录 `data/luts`）；`LutRef = { lutId, amount }` 作为一个**独立于 `Adjustments`** 的并列字段，跟着 `params` 一起进会话步骤和作品配方；渲染用 `TEXTURE_3D` + 三线性，插在 shader 最后一段；缩略图用当前照片在离屏画布上真渲染。

**Tech Stack:** TypeScript / React 18 / node:sqlite / WebGL2 / vitest / Playwright（真机探针）

**Spec:** `docs/superpowers/specs/2026-10-05-lut-design.md`

## 执行中被证伪的几处（计划是活文档，实现期发现计划错了就写回这儿）

1. **T1 解析器**：计划里"先判数据行、最后判 `size === 0`"的顺序与计划自己的测试
   （`parseCube('hello world\n')` 期望「不是 .cube」）自相矛盾 —— 见 `shared/lut.ts:100-103`：
   **见过 `LUT_3D_SIZE` 之前，非关键字行不当数据行**。
2. **T2 的 `texelCoord` 不能先钳输入**：计划原式 `(clamp01(v)-lo)/…` 让 domain=[0,2] 的
   输入 2 落进表的中间，而计划自己的 domain 测试要求命中最后一格。现在是
   `(v-lo)/max(hi-lo,1e-6)` 再钳坐标（`src/core/lut.ts:23-26`）——管线的输入由
   `applyLut` 先钳（和 shader 块首同构）。
3. **T2 顺序契约测试的人造 cube**：计划给的 `[min(1, r*1.8), g*0.5, b]` 实测两种顺序
   只差 0.00458，够不到计划自己写的阈值 0.05（正是计划警告过的"恒真断言"坑）。
   换成 gamma 0.25 → 差 0.0986。
4. ★ **shader 采样要补半个纹素**（T2 审查抓到、T5 照做）：`.cube` 第 i 格对应输入
   `i/(n−1)`，而 GL 的纹素中心在 `(i+0.5)/n`。直接把归一化的 t 交给 `texture(uLut, t)`
   会偏最多半格（n=2 时输入 0.25 采到纯黑）。已写进 Task 5 的 shader 片段：
   `float n = float(textureSize(uLut, 0).x); vec3 u = (t*(n-1.0)+0.5)/n;`

## Global Constraints

- **管线顺序是契约**：LUT 永远在最后（暗角之后、`fragColor` 之前）。改了 = 所有老图颜色都变。
- **强度 0 = 逐像素不变**（`mix(..., 0.0)`）；没装滤镜时 `uLutOn = 0`。
- **`LutRef` 不进 `Adjustments`**（那是个"十五个数字"的 record，被 `toUnit`/`PARAM_KEYS`/`prompt`/照调消费）。
- `.cube`：只认 **3D**、级数 **2–64**、文件 **≤8 MB**、每人 **≤30 个**、名字 **1–30 字且不重名**（忽略大小写）、**算进 5 GB 配额**。
- 错误文案照 spec §6.3 那张表，一个字别改（那是给用户看的）。
- 服务端写入时**一律把认不出来的 `LutRef` 清成 null**（纵深防御，别留悬空引用）。
- 老数据（没有 `lut` 键）一律当 null，不迁移、不报错。
- 每个任务结束前：`npm test` 绿 + `npm run typecheck` 绿（vitest 不做类型检查，两个都要）。
- 提交信息用中文，格式照仓库习惯（`feat(滤镜): …` / `fix(滤镜): …`），结尾不加署名以外的内容。
- ⚠️ 后端**不热重载**：动了 `server/` 要在验收时重启 `npm run dev`。
- ⚠️ `npm run check:layout` 每跑一次注册一个临时账号（限 20/小时），别连跑。

```ts
// shared/lut.ts
/**
 * 滤镜（LUT）的类型、常量与 `.cube` 解析。**前后端共用一份** ——
 * 客户端导入前先解一遍（即时反馈），服务端再解一遍（不信前端）。
 * 设计：docs/superpowers/specs/2026-10-05-lut-design.md
 */

/** 服务器上一条滤镜的元数据（接口回给客户端的那一面）。 */
export type LutMeta = {
  id: number
  name: string
  /** 级数 n（.cube 的 LUT_3D_SIZE） */
  size: number
  bytes: number
  createdAt: number
}

/**
 * **这张图正用着哪个滤镜、强度多少**。
 *
 * ⚠️ 它**不进 `Adjustments`**：那是个"十五个数字"的 record，被 toUnit /
 * PARAM_KEYS / 范围表 / 提示词 / 照调那五处消费，塞一个引用进去会让每一处
 * 都要处理"这一格不是数字"。设计 §3.2。
 */
export type LutRef = { lutId: number; amount: number }

/**
 * 解析好的颜色表。
 * `rgba` 是 size³×4 的 RGBA8，**红变最快**（和 `texture(uLut, vec3(r,g,b))`
 * 的取样方向、以及 texImage3D 的 x-fastest 约定一致）。
 */
export type Cube = {
  size: number
  rgba: Uint8Array
  domainMin: [number, number, number]
  domainMax: [number, number, number]
  title: string | null
}

export const MAX_LUT_FILE_BYTES = 8 * 1024 * 1024
export const MAX_LUTS = 30
export const MAX_LUT_SIZE = 64
export const MIN_LUT_SIZE = 2
export const MAX_LUT_NAME = 30

/** 解析失败的统一错误。**message 是给用户看的中文**（spec §6.3）。 */
export class LutParseError extends Error {
  constructor(message: string) {
    super(message)
    this.name = 'LutParseError'
  }
}

const clamp01 = (v: number): number => (v < 0 ? 0 : v > 1 ? 1 : v)
/** 允许一点点越界（有些导出工具会写 1.000001），超过这个就是坏文件 */
const EPS = 0.001

export function parseCube(text: string): Cube {
  const lines = text.split(/\r?\n/)
  let size = 0
  let domainMin: [number, number, number] = [0, 0, 0]
  let domainMax: [number, number, number] = [1, 1, 1]
  let title: string | null = null
  const values: number[] = []

  for (let i = 0; i < lines.length; i++) {
    const line = lines[i]!.trim()
    if (!line || line.startsWith('#')) continue
    const head = line.split(/\s+/)[0]!.toUpperCase()

    if (head === 'TITLE') {
      const m = /^TITLE\s+"?([^"]*)"?\s*$/i.exec(line)
      const t = (m?.[1] ?? '').trim()
      title = t || null
      continue
    }
    if (head === 'LUT_1D_SIZE') {
      throw new LutParseError('这是 1D 滤镜，暂时只支持 3D 的（常见的滤镜都是 3D）。')
    }
    if (head === 'LUT_3D_SIZE') {
      const n = Number(line.split(/\s+/)[1])
      if (!Number.isInteger(n) || n > MAX_LUT_SIZE || n < MIN_LUT_SIZE) {
        throw new LutParseError(n > MAX_LUT_SIZE
          ? `这个滤镜是 ${n} 级的，太大了 —— 目前支持 ${MAX_LUT_SIZE} 级以内。`
          : '这个文件不是 .cube 格式的滤镜。')
      }
      size = n
      continue
    }
    if (head === 'DOMAIN_MIN' || head === 'DOMAIN_MAX') {
      const nums = line.split(/\s+/).slice(1)
      const triple = nums.map(Number) as [number, number, number]
      if (triple.length !== 3 || triple.some((v) => !Number.isFinite(v))) {
        throw new LutParseError(`这个文件读不出来（第 ${i + 1} 行的数据不对），可能下载的时候坏了。`)
      }
      if (head === 'DOMAIN_MIN') domainMin = triple
      else domainMax = triple
      continue
    }

    // 剩下的一律当数据行：恰好三个数，且都在 [0,1] 附近
    const parts = line.split(/\s+/)
    if (parts.length !== 3) {
      throw new LutParseError(`这个文件读不出来（第 ${i + 1} 行的数据不对），可能下载的时候坏了。`)
    }
    for (const p of parts) {
      const v = Number(p)
      if (!Number.isFinite(v) || v < -EPS || v > 1 + EPS) {
        throw new LutParseError(`这个文件读不出来（第 ${i + 1} 行的数据不对），可能下载的时候坏了。`)
      }
      values.push(clamp01(v))
    }
  }

  if (size === 0) throw new LutParseError('这个文件不是 .cube 格式的滤镜。')
  if (values.length !== size * size * size * 3) {
    throw new LutParseError(
      `这个文件读不出来（应该有 ${size * size * size} 行数据，实际读到 ${Math.floor(values.length / 3)} 行），` +
      '可能下载的时候坏了。')
  }

  const rgba = new Uint8Array(size * size * size * 4)
  for (let i = 0, o = 0; i < values.length; i += 3, o += 4) {
    rgba[o] = Math.round(values[i]! * 255)
    rgba[o + 1] = Math.round(values[i + 1]! * 255)
    rgba[o + 2] = Math.round(values[i + 2]! * 255)
    rgba[o + 3] = 255
  }
  return { size, rgba, domainMin, domainMax, title }
}

/** 名字合法吗（trim 之后 1–30 字）。 */
export const lutNameOk = (name: string): boolean => {
  const t = name.trim()
  return t.length >= 1 && t.length <= MAX_LUT_NAME
}

/** 两个名字算不算同一个（忽略首尾空格与大小写）—— 对话里对号唯一的判据。 */
export const sameLutName = (a: string, b: string): boolean =>
  a.trim().toLowerCase() === b.trim().toLowerCase()

/**
 * `LutRef` 的**形状**归一化（它存不存在由服务端查库判，见 server/luts.ts）。
 * amount 钳到 0–100 取整；id 必须是正整数，否则回 null（当"没有滤镜"）。
 */
export function normalizeLutRef(raw: unknown): LutRef | null {
  if (typeof raw !== 'object' || raw === null || Array.isArray(raw)) return null
  const o = raw as Record<string, unknown>
  const lutId = Number(o.lutId)
  const amount = Number(o.amount)
  if (!Number.isInteger(lutId) || lutId <= 0) return null
  if (!Number.isFinite(amount)) return null
  return { lutId, amount: Math.max(0, Math.min(100, Math.round(amount))) }
}
```

```ts
// src/core/lut.test.ts
import { describe, it, expect } from 'vitest'
import type { Cube } from '../../shared/lut.ts'
import { applyLut, sampleCube } from './lut.ts'
import { applyTone } from './tone.ts'
import { toUnit, ZERO } from '../../shared/adjustments.ts'

/** 由函数造一个 size 级 cube（红变最快）。 */
function makeCube(size: number, fn: (r: number, g: number, b: number) => [number, number, number]): Cube {
  const rgba = new Uint8Array(size * size * size * 4)
  let o = 0
  for (let b = 0; b < size; b++)
    for (let g = 0; g < size; g++)
      for (let r = 0; r < size; r++) {
        const v = fn(r / (size - 1), g / (size - 1), b / (size - 1))
        rgba[o++] = Math.round(v[0] * 255)
        rgba[o++] = Math.round(v[1] * 255)
        rgba[o++] = Math.round(v[2] * 255)
        rgba[o++] = 255
      }
  return { size, rgba, domainMin: [0, 0, 0], domainMax: [1, 1, 1], title: null }
}

const identity = (n = 2) => makeCube(n, (r, g, b) => [r, g, b])
/** 红蓝对调，用来验方向 */
const swapRB = (n = 2) => makeCube(n, (r, g, b) => [b, g, r])

describe('applyLut', () => {
  it('强度 0 = 逐像素不变（含钳制语义）', () => {
    const cube = swapRB()
    for (const px of [[0, 0, 0], [0.25, 0.5, 0.75], [1, 1, 1], [0.123, 0.987, 0.5]] as const) {
      expect(applyLut(cube, [...px], 0)).toEqual([...px])
    }
  })

  it('强度 100 = 完全查表（红蓝对调能对上）', () => {
    const [r, g, b] = applyLut(swapRB(), [0, 0.5, 1], 100)
    expect(r).toBeCloseTo(1, 2)
    expect(g).toBeCloseTo(0.5, 2)
    expect(b).toBeCloseTo(0, 2)
  })

  it('强度在中间就是线性混合', () => {
    const half = applyLut(swapRB(4), [0.2, 0.5, 0.8], 50)
    expect(half[0]).toBeCloseTo((0.2 + 0.8) / 2, 2)
  })

  it('恒等表在任何强度下都不变', () => {
    const [r, g, b] = applyLut(identity(4), [0.3, 0.6, 0.9], 100)
    expect(r).toBeCloseTo(0.3, 2)
    expect(g).toBeCloseTo(0.6, 2)
    expect(b).toBeCloseTo(0.9, 2)
  })

  it('三线性：2 级恒等表在中间点插值正确', () => {
    const [r, g, b] = sampleCube(identity(2), 0.5, 0.25, 0.75)
    expect(r).toBeCloseTo(0.5, 2)
    expect(g).toBeCloseTo(0.25, 2)
    expect(b).toBeCloseTo(0.75, 2)
  })

  it('domain 参与换算', () => {
    const cube = identity(2)
    cube.domainMax = [2, 2, 2]
    // 输入 2（顶层）应命中表里最后一格 = 白
    const [r] = sampleCube(cube, 2, 2, 2)
    expect(r).toBeCloseTo(1, 2)
  })
})

describe('管线顺序（契约）', () => {
  it('LUT 在参数之后：两种顺序的结果必须不同（把这行反过来 = 红）', () => {
    const cube = makeCube(4, (r, g, b) => [Math.min(1, r * 1.8), g * 0.5, b])  // 强非线性
    const u = toUnit({ ...ZERO, exposure: 40 })
    const px: [number, number, number] = [0.3, 0.55, 0.2]
    const correctOrder = applyLut(cube, applyTone(px, u), 100)
    const wrongOrder = applyTone(applyLut(cube, px, 100), u)
    const diff = correctOrder.map((v, i) => Math.abs(v - wrongOrder[i]!)).reduce((a, b) => a + b, 0)
    expect(diff).toBeGreaterThan(0.05)   // 差别要明显，别拿噪声当断言
  })
})
```

```ts
// src/core/lut.ts
import type { Cube } from '../../shared/lut.ts'

/**
 * LUT 查表的 **CPU 对照实现** —— 和 `render/shader.ts` 里第 7 段是同一套数学
 * （三线性 + 按强度混合 + domain 换算）。
 *
 * ⚠️ 改这里必须同步改 shader（反过来也一样），和 `tone.ts` 对 `shader.ts`
 * 那条老规矩一致。它存在的理由：GPU 那半进不了 vitest，而
 * 「强度 0 逐像素不变」和「LUT 排在参数之后」这两条是**契约**，必须有测试。
 */

const clamp01 = (v: number): number => (v < 0 ? 0 : v > 1 ? 1 : v)
const lerp = (a: number, b: number, t: number): number => a + (b - a) * t

/** 0–1 的输入 → 纹理坐标（0–n−1）。和 shader 的 (q−min)/(max−min) 同一套。 */
function texelCoord(v: number, lo: number, hi: number, n: number): number {
  const t = (clamp01(v) - lo) / Math.max(hi - lo, 1e-6)
  return clamp01(t) * (n - 1)
}

/** 三线性采样一个 cube。输入/输出都是 0–1 的 sRGB。 */
export function sampleCube(cube: Cube, r: number, g: number, b: number): [number, number, number] {
  const n = cube.size
  const x = texelCoord(r, cube.domainMin[0], cube.domainMax[0], n)
  const y = texelCoord(g, cube.domainMin[1], cube.domainMax[1], n)
  const z = texelCoord(b, cube.domainMin[2], cube.domainMax[2], n)
  const x0 = Math.floor(x), y0 = Math.floor(y), z0 = Math.floor(z)
  const x1 = Math.min(x0 + 1, n - 1), y1 = Math.min(y0 + 1, n - 1), z1 = Math.min(z0 + 1, n - 1)
  const fx = x - x0, fy = y - y0, fz = z - z0
  // 红变最快 → index = x + y*n + z*n²（和 texImage3D 的 x-fastest 一样）
  const at = (i: number, j: number, k: number, c: number): number =>
    cube.rgba[((k * n + j) * n + i) * 4 + c]! / 255
  const out: [number, number, number] = [0, 0, 0]
  for (let c = 0; c < 3; c++) {
    const c00 = lerp(at(x0, y0, z0, c), at(x1, y0, z0, c), fx)
    const c10 = lerp(at(x0, y1, z0, c), at(x1, y1, z0, c), fx)
    const c01 = lerp(at(x0, y0, z1, c), at(x1, y0, z1, c), fx)
    const c11 = lerp(at(x0, y1, z1, c), at(x1, y1, z1, c), fx)
    out[c] = lerp(lerp(c00, c10, fy), lerp(c01, c11, fy), fz)
  }
  return out
}

/**
 * 按强度（0–100）把查表结果和原色混合。**amount = 0 时逐像素等于入参**
 * —— 这是 spec §9 那条测试，别在这里加任何"顺手"的运算。
 */
export function applyLut(
  cube: Cube, rgb: readonly [number, number, number], amount: number,
): [number, number, number] {
  const q: [number, number, number] = [clamp01(rgb[0]), clamp01(rgb[1]), clamp01(rgb[2])]
  const a = clamp01(amount / 100)
  if (a === 0) return q
  const m = sampleCube(cube, q[0], q[1], q[2])
  return [lerp(q[0], m[0], a), lerp(q[1], m[1], a), lerp(q[2], m[2], a)]
}
```

```ts
import type { PublicUser } from './account.ts'
import type { Db } from './db.ts'
import { HttpError, asObject, str } from './http.ts'
import type { Storage } from './storage.ts'
import {
  MAX_LUTS, MAX_LUT_FILE_BYTES, LutParseError, lutNameOk, normalizeLutRef, parseCube,
  type Cube, type LutMeta, type LutRef,
} from '../shared/lut.ts'

export type LutDeps = { db: Db; storage: Storage; now?: () => number }
const nowMs = (d: LutDeps): number => (d.now ? d.now() : Date.now())

export type LutRow = {
  id: number; user_id: number; name: string; stored_name: string
  size: number; bytes: number; created_at: number
}

const toMeta = (r: LutRow): LutMeta =>
  ({ id: r.id, name: r.name, size: r.size, bytes: r.bytes, createdAt: r.created_at })

/**
 * 取一条**属于这个人的**滤镜。和 works/sessions 那条规矩一样：
 * 不是他的和不存在回**同一句话**（分开说就等于告诉别人哪些 id 是真的）。
 */
export function loadOwnedLut(id: number, user: PublicUser, deps: LutDeps): LutRow {
  const row = deps.db.raw
    .prepare('SELECT * FROM luts WHERE id = ? AND user_id = ?')
    .get(id, user.id) as LutRow | undefined
  if (!row) throw new HttpError('BAD_REQUEST', '没有这个滤镜', 404)
  return row
}

export function listLuts(user: PublicUser, deps: LutDeps): { luts: LutMeta[] } {
  const rows = deps.db.raw
    .prepare('SELECT * FROM luts WHERE user_id = ? ORDER BY created_at DESC, id DESC')
    .all(user.id) as LutRow[]
  return { luts: rows.map(toMeta) }
}

/** 重名（忽略大小写）的统一判据 —— 导入和改名共用一句话。 */
function assertNameFree(name: string, user: PublicUser, deps: LutDeps, exceptId = 0): void {
  const hit = deps.db.raw
    .prepare('SELECT id FROM luts WHERE user_id = ? AND name = ? AND id != ?')
    .get(user.id, name, exceptId)
  if (hit) throw new HttpError('BAD_REQUEST', `已经有一个叫「${name}」的滤镜了，换个名字。`)
}

export async function createLut(
  body: unknown, user: PublicUser, deps: LutDeps,
): Promise<{ lut: LutMeta }> {
  const o = asObject(body)
  const text = str(o.cube)
  if (!text) throw new HttpError('BAD_REQUEST', '没有收到文件内容')
  // 文本长度就是字节数的上界（UTF-8 下 ASCII 一字一字节；.cube 是纯 ASCII）
  if (text.length > MAX_LUT_FILE_BYTES) throw new HttpError('BAD_REQUEST', '这个文件超过 8 MB 了。')

  let cube: Cube
  try {
    cube = parseCube(text)
  } catch (e) {
    if (e instanceof LutParseError) throw new HttpError('BAD_REQUEST', e.message)
    throw e
  }

  // 名字：客户端给的 → .cube 里的 TITLE → 兜底
  const raw = str(o.name).trim() || cube.title?.trim() || '未命名'
  const name = raw.slice(0, 30)
  if (!lutNameOk(name)) throw new HttpError('BAD_REQUEST', '滤镜名字要 1–30 个字。')

  const count = (deps.db.raw
    .prepare('SELECT COUNT(*) AS n FROM luts WHERE user_id = ?')
    .get(user.id) as { n: number }).n
  if (count >= MAX_LUTS) throw new HttpError('BAD_REQUEST', `最多 ${MAX_LUTS} 个滤镜，先删掉几个再导入。`)
  assertNameFree(name, user, deps)

  // 配额和落盘都走既有的那一套（Task 4 会把 luts 计入 storedBytes）
  assertRoomFor(deps.db, user.id, text.length, 'lut')
  const storedName = await deps.storage.save(new TextEncoder().encode(text), '.cube')
  try {
    const r = deps.db.raw.prepare(
      `INSERT INTO luts (user_id, name, stored_name, size, bytes, created_at)
       VALUES (?, ?, ?, ?, ?, ?)`,
    ).run(user.id, name, storedName, cube.size, text.length, nowMs(deps))
    const row = deps.db.raw.prepare('SELECT * FROM luts WHERE id = ?').get(Number(r.lastInsertRowid)) as LutRow
    return { lut: toMeta(row) }
  } catch (e) {
    // 插不进库就把刚写的文件收回来（和 handleCreateWork 同一条）
    await deps.storage.remove(storedName).catch(() => {})
    // UNIQUE 兜底：两个请求同时导入同一个名字时，上面那次检查会双双放行
    if (String((e as Error).message).includes('UNIQUE')) {
      throw new HttpError('BAD_REQUEST', `已经有一个叫「${name}」的滤镜了，换个名字。`)
    }
    throw e
  }
}

export async function handleLutFile(
  id: number, user: PublicUser, deps: LutDeps,
): Promise<{ bytes: Uint8Array; contentType: string }> {
  const row = loadOwnedLut(id, user, deps)
  return { bytes: await deps.storage.read(row.stored_name), contentType: 'text/plain; charset=utf-8' }
}

export function renameLut(
  id: number, body: unknown, user: PublicUser, deps: LutDeps,
): { lut: LutMeta } {
  const row = loadOwnedLut(id, user, deps)
  const name = str(asObject(body).name).trim().slice(0, 30)
  if (!lutNameOk(name)) throw new HttpError('BAD_REQUEST', '滤镜名字要 1–30 个字。')
  if (name !== row.name) assertNameFree(name, user, deps, id)
  deps.db.raw.prepare('UPDATE luts SET name = ? WHERE id = ?').run(name, id)
  return { lut: toMeta({ ...row, name }) }
}

/** 有几条会话的某一步正用着它（**逐条解析 steps 数出来**，不是 SQL 模糊匹配）。 */
export function lutUsage(id: number, user: PublicUser, deps: LutDeps): { sessions: number } {
  const rows = deps.db.raw
    .prepare('SELECT steps FROM sessions WHERE user_id = ?')
    .all(user.id) as { steps: string }[]
  let n = 0
  for (const r of rows) {
    let steps: unknown
    try { steps = JSON.parse(r.steps) } catch { continue }   // 坏 JSON 不该拖垮删除
    if (Array.isArray(steps) && steps.some((s) => (s as { lut?: LutRef | null }).lut?.lutId === id)) n++
  }
  return { sessions: n }
}

export async function deleteLut(id: number, user: PublicUser, deps: LutDeps): Promise<{ ok: true }> {
  const row = loadOwnedLut(id, user, deps)
  deps.db.raw.prepare('DELETE FROM luts WHERE id = ?').run(id)
  // Task 4 会在这里补上「把这个人的会话步骤里指向它的 lut 清成 null」
  await deps.storage.remove(row.stored_name).catch((e) => {
    console.error('删滤镜：文件没删掉（记录已清，成了孤儿）：', e)
  })
  return { ok: true }
}

/**
 * 把客户端/库里来的一个 `LutRef` 解析成可信的：**id 必须是这个人的、存在的**。
 * 认不出来回 null（= 没有滤镜）—— 这是"不许悬空引用"那道闸的落点（Task 4 用它）。
 */
export function resolveLutRef(db: Db, userId: number, raw: unknown): LutRef | null {
  const ref = normalizeLutRef(raw)
  if (!ref) return null
  const hit = db.raw.prepare('SELECT id FROM luts WHERE id = ? AND user_id = ?').get(ref.lutId, userId)
  return hit ? ref : null
}
```

`src/render/shader.ts` 的 `FRAGMENT_SRC`：

```glsl
uniform sampler3D uLut;         // the user's color lookup table (3D texture)
uniform float uLutOn;           // 1.0 when a LUT is bound, 0.0 otherwise
uniform float uLutAmount;       // strength, 0..1

```

2. `main()` 末尾那两行之间插入（**注释必须英文**）：

```glsl
  // 7. LUT (color lookup) -- ALWAYS THE LAST STEP. This is a contract, not a
  //    preference (see the design doc 2026-10-05 §4.1): every saved work was
  //    rendered through this order, so moving the LUT earlier would change the
  //    colors of every existing photo. Do not reorder.
  //
  //    uLutOn is 0 when nothing is bound, which makes lutAmt 0 and the whole
  //    block an exact identity -- strength 0 must be pixel-for-pixel identical
  //    to having no LUT at all.
  //
  //    The half-texel correction is NOT optional: a .cube entry i stands for
  //    the input i/(n-1), while GL puts texel i's center at (i+0.5)/n. Handing
  //    the normalized value straight to texture() shifts every lookup by up to
  //    half a texel (an n=2 table turns input 0.25 into pure black). The CPU
  //    twin (src/core/lut.ts) samples in endpoint-inclusive index space, and it
  //    is what the acceptance probe compares against -- the two must agree.
  float lutAmt = uLutOn * uLutAmount;
  if (lutAmt > 0.0) {
    vec3 q = clamp(c, 0.0, 1.0);
    vec3 t = clamp((q - uLutDomainMin) / max(uLutDomainMax - uLutDomainMin, vec3(1e-6)),
                   vec3(0.0), vec3(1.0));
    float n = float(textureSize(uLut, 0).x);
    vec3 u = (t * (n - 1.0) + 0.5) / n;
    c = mix(q, texture(uLut, u).rgb, lutAmt);
  }
```

```ts
import { TonePipeline } from './pipeline'
import type { DecodedImage } from '../image/decode'
import type { Adjustments } from '../../shared/adjustments.ts'
import type { Cube } from '../../shared/lut.ts'

/**
 * 缩略图预览器：**用当前这张照片**给每个滤镜渲染一张小方图（设计 §4.4 / spec §8.3
 * "用当前这张照片渲染 —— 比「黄昏」两个字有用得多"）。
 *
 * 做法：先给整张照片做一份 256px 的小拷贝（一次），之后每个滤镜都是在这张小图上
 * 重画一下（很便宜），再 cover 裁成方形、转 dataURL。
 *
 * ⚠️ 它自己的 canvas 是**离屏的**（`document.createElement`，不进 DOM）——
 * 别拿主画布来画：那会把用户眼前的图闪成一张小图。
 */
export const PREVIEW_SRC_MAX = 256
export const LUT_THUMB_SIZE = 132

/** cover 裁切：把 srcW×srcH 里最大的一块正方形框出来（多余的部分两端各切一半）。 */
export function coverCrop(srcW: number, srcH: number, dstW: number, dstH: number) {
  const side = Math.min(srcW, srcH)
  return {
    sx: Math.round((srcW - side) / 2),
    sy: Math.round((srcH - side) / 2),
    sw: side,
    sh: side,
  }
}

export type LutPreview = {
  /** 换照片（可重复调，认对象身份；同一张不会重做） */
  setImage(image: DecodedImage): Promise<void>
  /** 画一张：当前参数 + 这个 cube（null = 不用滤镜）。失败回 null。 */
  render(params: Adjustments, cube: Cube | null): string | null
  dispose(): void
}

export function createLutPreview(): LutPreview {
  const dpr = Math.min(2, Math.max(1, Math.round(globalThis.devicePixelRatio || 1)))
  const size = LUT_THUMB_SIZE * dpr
  const small = document.createElement('canvas')      // 照片的小拷贝，管线画在这上面
  const out = document.createElement('canvas')        // 方形的那张（裁 + 缩）
  out.width = size
  out.height = size
  const outCtx = out.getContext('2d')!
  let pipe: TonePipeline | null = null
  let lastBitmap: ImageBitmap | null = null

  const ensurePipe = (): TonePipeline => {
    if (!pipe) pipe = new TonePipeline(small)
    return pipe
  }

  return {
    async setImage(image) {
      if (lastBitmap === image.bitmap) return
      const scale = PREVIEW_SRC_MAX / Math.max(image.width, image.height)
      const w = Math.max(1, Math.round(image.width * scale))
      const h = Math.max(1, Math.round(image.height * scale))
      const src = document.createElement('canvas')
      src.width = w
      src.height = h
      // 缩图用 2D 画布做（createImageBitmap 带 resizeWidth 在 Safari 上不齐）
      src.getContext('2d')!.drawImage(image.bitmap, 0, 0, w, h)
      const bitmap = await createImageBitmap(src)
      lastBitmap?.close()
      lastBitmap = bitmap
      const p = ensurePipe()
      p.setImage({ bitmap, width: w, height: h })
      p.resizeToImage()
    },
    render(params, cube) {
      if (!lastBitmap) return null
      try {
        const p = ensurePipe()
        p.setLut(cube)
        p.render(params, 100)        // 缩略图一律按满强度画：看的是"这个滤镜长什么样"
        const crop = coverCrop(small.width, small.height, size, size)
        outCtx.drawImage(small, crop.sx, crop.sy, crop.sw, crop.sh, 0, 0, size, size)
        return out.toDataURL('image/jpeg', 0.82)
      } catch (e) {
        console.error('滤镜缩略图没画出来：', e)
        return null
      }
    },
    dispose() {
      pipe?.dispose()
      pipe = null
      lastBitmap?.close()
      lastBitmap = null
    },
  }
}
```

⚠️ `DecodedImage` 的字段名以 `src/image/decode.ts` 为准（`{ bitmap, width, height }`）—— 写之前 `grep "export type DecodedImage" -A 6 src/image/decode.ts` 核一遍。

```ts
import { useCallback, useEffect, useRef, useState } from 'react'
import { listLuts, lutFileText } from '../api/luts.ts'
import { parseCube, type Cube, type LutMeta, type LutRef } from '../../shared/lut.ts'
import { createLutPreview, type LutPreview } from '../render/lutPreview.ts'
import type { DecodedImage } from '../image/decode'
import type { Adjustments } from '../../shared/adjustments.ts'

/**
 * 滤镜的客户端状态：**清单、当前那个的 cube、缩略图**。
 *
 * 三件事住在一起的理由：它们都挂在"清单 + 当前选中的 id"上，分开写就会出现
 * "清单刷新了、cube 还是旧的"这种半新半旧的状态。
 */
export function useLuts({ lut, image, params }: {
  lut: LutRef | null
  image: DecodedImage | null
  params: Adjustments
}) {
  const [luts, setLuts] = useState<LutMeta[]>([])
  const [cube, setCube] = useState<Cube | null>(null)
  const [thumbs, setThumbs] = useState<{ none: string | null; byId: Record<number, string> }>(
    { none: null, byId: {} })

  /** id → 解析好的 cube。取过一次就不再取（清单小、每个几十 KB~几 MB，够放） */
  const cubes = useRef(new Map<number, Cube>())
  const preview = useRef<LutPreview | null>(null)
  const lutId = lut?.lutId ?? null
  // 两条"这一趟还算不算数"的序号：切滤镜 / 换照片时各自作废前面的异步
  const cubeSeq = useRef(0)
  const thumbSeq = useRef(0)

  // ⚠️ 懒建 + 卸载时 dispose：**StrictMode 会把挂载重放一遍**，在 effect 里
  //    建、在 cleanup 里 dispose 的话，第二次挂载拿到的是一个已经 dispose 的实例。
  const ensurePreview = (): LutPreview => {
    if (!preview.current) preview.current = createLutPreview()
    return preview.current
  }
  useEffect(() => () => { preview.current?.dispose(); preview.current = null }, [])

  const loadCube = useCallback(async (id: number): Promise<Cube | null> => {
    const hit = cubes.current.get(id)
    if (hit) return hit
    try {
      const c = parseCube(await lutFileText(id))
      cubes.current.set(id, c)
      return c
    } catch (e) {
      console.error('滤镜取不回来或者读不出来：', e)
      return null
    }
  }, [])

  const reload = useCallback(async (): Promise<LutMeta[]> => {
    try {
      const { luts: list } = await listLuts()
      setLuts(list)
      return list
    } catch (e) {
      console.error('滤镜清单没取回来：', e)
      return []
    }
  }, [])

  // 登录后拉一次清单（App 挂载时）
  useEffect(() => { void reload() }, [reload])

  // 当前滤镜换了 → 取它的 cube（认不出来的当"没有"）
  useEffect(() => {
    const seq = ++cubeSeq.current
    if (lutId === null) { setCube(null); return }
    void loadCube(lutId).then((c) => { if (seq === cubeSeq.current) setCube(c) })
  }, [lutId, loadCube])

  // 换照片 → 缩略图作废（下次打开格子重画；这里的 `image` 刻意进依赖）
  useEffect(() => {
    thumbSeq.current++
    setThumbs({ none: null, byId: {} })
  }, [image])

  /**
   * 打开格子时叫一次：把还没有的缩略图补齐。
   * ⚠️ 每个滤镜**先把 cube 取到手**再画 —— 没取到就不画那一格（格子会显示占位）。
   */
  const ensureThumbs = useCallback((imageNow: DecodedImage | null, paramsNow: Adjustments) => {
    if (!imageNow) return
    const seq = ++thumbSeq.current
    const p = ensurePreview()
    void (async () => {
      await p.setImage(imageNow)
      if (seq !== thumbSeq.current) return
      const none = p.render(paramsNow, null)
      const byId: Record<number, string> = {}
      for (const l of luts) {
        const c = await loadCube(l.id)
        if (seq !== thumbSeq.current) return
        const t = c ? p.render(paramsNow, c) : null
        if (t) byId[l.id] = t
      }
      setThumbs({ none, byId })
    })().catch((e) => console.error('滤镜缩略图没画出来：', e))
  }, [luts, loadCube])

  return { luts, cube, thumbs, ensureThumbs, reload }
}
```

- [ ] **Step 4: `validate.ts`**

```ts
/**
 * 模型的滤镜决定 → 可信的 `LutDecision`。
 *
 * 三条规矩：名字必须在**用户自己的清单**里（大小写和首尾空格不算数）；
 * `name` 空串 = 摘掉；`amount` 取整钳 0–100（缺省 100）。
 * 认不出来回 null（= 不动），并且**要留 degraded 信号** —— 模型给了个我们没有
 * 的东西，那是"这次没全采纳"，不是正常情况。
 */
function normalizeLutChoice(raw: unknown, names: readonly string[]): { lut: LutDecision | null; dropped: boolean } {
  if (typeof raw !== 'object' || raw === null || Array.isArray(raw)) return { lut: null, dropped: false }
  const o = raw as Record<string, unknown>
  const name = typeof o.name === 'string' ? o.name.trim() : null
  if (name === null) return { lut: null, dropped: false }
  if (name === '') return { lut: { name: '', amount: 0 }, dropped: false }
  const hit = names.find((n) => sameLutName(n, name))
  if (!hit) return { lut: null, dropped: true }
  const amount = Number(o.amount)
  return { lut: { name: hit, amount: Number.isFinite(amount) ? Math.max(0, Math.min(100, Math.round(amount))) : 100 }, dropped: false }
}
```
