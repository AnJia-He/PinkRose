# 苹果端发布验收清单

> 目标：用一次有边界的人工验收判断 PinkRose 能不能交给苹果用户，
> 而不是继续加功能。只有清单中的阻断项都通过，才能宣称当前版本可用。

## 一、当前可交付范围

以下能力已在代码中接通，并有自动化或 WebKit 探针证据：

- 照片导入、调色、裁剪、曲线、HSL、局部蒙版、人像、磨皮和撤销。
- 文字、贴纸、形状、抠图、换背景、拼图、长图、证件照和打印。
- JPG / PNG / WebP / AVIF / TIFF 导出；本机有编码器时显示 HEIC。
- 批量处理、ZIP 下载或系统分享、社交尺寸打包。
- 实况照片识别；ID 一致时导出当前 JPG 成片和原 MOV 的兼容 ZIP。
- PWA 主屏安装、安全区、触控、Apple Pencil 压感、离线能力提示。
- 浏览器实时相机，以及本机相机桥、gphoto2、Canon CCAPI、Sony 遥控接线。

已验证的最近证据：

- 磨皮 WebKit 390px：`9/9`。
- 实况照片 WebKit 390px：`14/14`。
- 文件分享 WebKit 390px：批量 ZIP、实况照片兼容包均为真实
  `application/zip`；取消分享不触发下载。
- 生产构建通过，首包预算通过。

## 二、iPhone 人工验收

建议使用一台真实 iPhone，Safari 保持最新系统版本。用同一账号测试以下路径，
每一步记录“通过 / 失败 / 不适用”，失败时记录页面文字和复现步骤，不记录密钥、
访问令牌或私人照片。

| # | 验收项 | 通过标准 |
| --- | --- | --- |
| 1 | 主屏安装 | Safari 分享菜单能“添加到主屏幕”；从主屏启动是 standalone，安全区不遮按钮 |
| 2 | 横竖屏 | 竖屏编辑、旋转横屏、再转回竖屏后画布和底部操作仍可达 |

| 16 | 相册回看 / 保存 | 保存作品后回到作品页能打开、下载、分享和继续编辑 |

## 三、iPad 人工验收

在竖屏和横屏各走一遍：

- 作品网格、调色面板和工具行不互相遮挡。
- 双指缩放、单指拖动和专注看图正常。
- 裁剪、透视和局部蒙版的把手有足够命中区。
- 外接键盘的撤销 / 重做快捷键可用。

## 四、真实相机与专业格式

下列项目必须有真实设备和文件证据；自动化假相机通过不算完成：

- gphoto2 USB / PTP/IP：连接的机身型号、实时取景、快门、参数读写和照片下载。
- Canon CCAPI：真实 Canon 型号、取景、快门、参数和存储卡导入。
- Sony Camera Remote：真实 Sony 型号、远程模式、取景、快门和存储卡导入。
- 厂商私有 SDK：按适配器加载点接入后，用真实机身验证能力声明与实际结果一致。
- RAW：在装有 RawTherapee、darktable 或 LibRaw 的 Mac 上，用厂商 RAW 验证尺寸、
  色彩、方向和高光恢复，并确认不是只读了内嵌 JPEG。
- HEIC 导出：在 macOS 的 `sips` 或带 HEIC delegate 的 ImageMagick 环境中验证真实字节。

## 五、明确不能宣称已完成

- Apple 原生 Live Photo `.pvt` 重封装。当前只能导出同 stem 的 JPG + MOV 兼容 ZIP。
- 完整广色域编辑。当前可识别源色域，并能从 sRGB 工作色域转换交付 Display P3，
  但不能恢复超出 sRGB 的源颜色。
- 没有转换器时的完整 RAW 解档。当前会诚实退回相机内嵌 JPEG 预览。
- 未经真实机身验证的私有相机协议或厂商 SDK 控制。

## 六、发布判定

每轮验收只允许两种结论：

1. **可发布**：所有阻断项通过；非阻断项写明限制后可以接受。
2. **暂不发布**：只修阻断项，再重跑对应最小验证，不重新展开一整轮功能开发。

阻断项包括：导入失败、编辑结果与导出不一致、撤销失效、分享/下载拿不到文件、
iPhone 关键按钮不可达、页面崩溃或隐私数据泄露。

非阻断项包括：某款未支持机型的私有相机协议、超出 sRGB 的编辑能力、
原生 Live Photo 重封装。它们应作为明确产品边界记录，而不是无限追加模拟功能。

## 七、微信小程序验收

小程序通过微信在 iPhone 上运行，发布前另走：

1. `npx tsc -p mini --noEmit`。
2. `node --test mini/tests/*.test.mjs`。
3. `npx vitest run --config mini/vitest.config.ts`。
4. `node scripts/sync-mini-shared.mjs --check`。
5. 微信开发者工具启动 `agent start`，依次运行三个 `mini/scripts/smoke*.cjs`。
6. 真机确认拍照、相册、AI、手动调色、人像、裁剪、对比、草稿恢复、保存相册、
   作品再次精修、默认风格和服务状态。

正式发布必须在微信公众平台替换正式 AppID，配置 HTTPS request 合法域名和隐私
保护指引，并移除开发版测试按钮；不得把 AppSecret 或 API Key 写进小程序包。
